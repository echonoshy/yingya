# 映芽 · 4秒无声循环动画

## 目标与固定输入
制作轻快、简洁的品牌字标循环动画。画面仅包含“映芽”两个汉字和一个小圆点，不加入其他文案、图像或字幕；无旁白、音乐及其他音轨。

- 输出规格：720 × 720，30 fps，严格4秒，共120帧。
- 背景：暖白 `#F6F4EE`；文字：近黑 `#172D43`；圆点：珊瑚橙 `#C54C35`。
- 字体：Noto Sans SC。
- 首尾视觉状态一致，循环接缝不出现位置、颜色、透明度或尺寸跳变。

## 故事与动作
使用一个连续镜头，不切场。“映芽”居中偏左，小圆点位于字标右侧，整体视觉居中。

| 时间 | 画面与动作 |
| --- | --- |
| 0.00–0.40秒 | 字标与圆点静稳呈现，建立识别。 |
| 0.40–1.20秒 | “映”轻轻向上跳起约12px，随后“芽”错开约0.12秒跟随；两个字分别回到基线，幅度克制，不旋转。 |
| 1.20–2.40秒 | 圆点沿短弧向右上方跃起，再回到原位；落点处做一次轻微压扁回弹，始终只有一个圆点，无拖尾或粒子。 |
| 2.40–3.20秒 | 两字与圆点共同上浮约4px后回落，形成轻巧收束。 |
| 3.20–4.00秒 | 完全恢复并保持初始状态，衔接下一轮。 |

以上为拟定的无声动作节奏，不涉及音频测量；4秒总长为硬约束。

## 视觉与构图
以大面积暖白留白衬托字标；文字保持清晰、可读，动效靠小幅位移和圆点弹性变化表达轻快感，不加阴影、纹理、边框或装饰。文字与圆点在整个运动范围内均保持安全边距。

## 制作路线与交付
采用可编辑文字、CSS圆形与GSAP时间轴，由HyperFrames合成。根据本次提供的能力信息，本地HyperFrames 0.8.30、GSAP、Chrome、FFmpeg及Noto Sans SC已可用；无需网络或外部媒体服务。

计划确认后制作可编辑源文件和审阅草稿；草稿确认后导出最终无声音轨MP4。制作时检查布局、对比度与关键动作，核验720 × 720、30 fps、120帧及循环接缝。MP4是否自动重复播放由播放器决定，视频内容本身按无缝循环设计。
