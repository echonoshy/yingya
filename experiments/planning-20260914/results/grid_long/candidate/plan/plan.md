# 60秒无声科普动画｜网格交易是什么？

## 目标与讲述角度
面向新手，用“在价格区间里搭一架交易阶梯”解释网格交易：预先划分价格层级，按规则分批买卖，而不是预测每次涨跌。以同一张图上的两轮局部交易贯穿，最后主动拆开“局部价差”与“账户盈利”的区别。

## 固定输入与边界
- 固定区间80至120元；价格线80、90、100、110、120，共五条线、四个间隔。
- 公式：间距＝(120−80)/4＝10元。
- 唯一成交演示：100→90→100→90→100；每次90元买1份，再于100元卖出该轮买入的同一份，共两轮。
- 每轮未扣成本价差为10元；不展示账户余额、总收益、收益率或完整挂单系统，不把局部交易外推为账户盈利。
- 买单需要现金，卖单需要已有持仓；成本减少价差。跌破区间可能持仓承压，持续上涨可能提前卖出。
- 所有数字均为虚构教学示例，非行情或收益预测，不提供投资建议。

## 故事与预计段落
| 时间 | 内容与可见事件 |
| --- | --- |
| 0–7秒 | 一条价格路径在区间内起伏，水平层级逐一浮现；提出“把价格区间分成格子，按规则分批买卖”。此时不出现成交标记。 |
| 7–18秒 | 建立80至120元图表，用括号数清五条价格线之间的四个间隔，展开10元间距公式。 |
| 18–34秒 | 沿100→90→100→90→100逐段推进；两次各用一枚带身份的“1份”筹码演示90买、100卖同一份。每轮结束显示未扣成本价差10元。 |
| 34–43秒 | 保留一轮交易摘要，分别揭示现金与持仓条件；再用公式说明交易成本减少价差，不假设成本数值。 |
| 43–55秒 | 同一区间变为两张情景图：跌破80时已有持仓承压；持续涨过120时，先前卖出的部分可能错过后续上涨。明确局部价差不等于账户盈利。 |
| 55–60秒 | 收束为“分层交易，不是稳赚”，保留风险结论及完整教学免责声明，静止阅读。 |

以上为无声版的设计时间分配，并非音频实测。制作时按阅读负荷落实为精确60秒、30fps时间线。

## 视觉与声音
使用既定浅米白画布、近黑蓝文字、蓝色买入和橙色卖出；中文采用Noto Sans SC。原创可编辑图表承担解释，文字只给标题、动作和结论。主图以价格为纵轴、示意步骤为横轴，不伪装真实行情。让价格点移动、订单成交和筹码转移形成可见因果；阅读阶段暂停动画。

完全无声，不加旁白、音乐或音效；不设逐字字幕，以画面文字独立完成说明。全片常驻“虚构教学示例｜非行情或收益预测｜不构成投资建议”，成交段另标“仅局部交易，非完整账户模拟”。
