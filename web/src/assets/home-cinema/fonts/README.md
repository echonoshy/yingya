# 首页字体

- `yingya-poster-heavy.woff2`：Adobe Source Han Serif CN Heavy 的固定首页文字子集，内部字体名称改为 Yingya Poster Subset，避免使用保留字体名称
- 官方原文件：https://raw.githubusercontent.com/adobe-fonts/source-han-serif/release/SubsetOTF/CN/SourceHanSerifCN-Heavy.otf
- 授权：同目录 SourceHanSerif-LICENSE.txt
- 子集文字：让想法有声有色从一句到段好故事映芽
- `bodoni-editorial.woff2`：既有 OFL Bodoni Moda Italic 的英文字句子集，保留可变字重与光学字号轴
- 子集句子：A little spark. A moving story.
- 子集工具：fontTools subset，WOFF2 / Brotli
- 字体仅由首页 CSS 使用，修改标题时应同步补充字形，正文仍使用共享 UI 字体
