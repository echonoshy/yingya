# Capability examples v1

Static examples for Yingya's capability explorer. This versioned directory is an immutable URL contract after release; create a new version directory when changing example assets.

- assets/headphones.png: original generated concept art; not a rendered user model.
- assets/infographic.png: original layout illustration, not execution of the Baoyu workflow.
- Other poster images: captures of existing runtime component examples.
- demo/: isolated, finite, user-started six-second playback. No API access or user uploads. Parent messaging checks both origin and source.
- demo/assets: copied using runtime/component-library.mjs install for model-stage, beam-network, title-reveal, flow-path and number-compare, from the approved prototype. Bundled third-party licenses and component provenance are retained next to their code.
- demo/fonts: Noto Sans SC font files and license. Three.js is loaded only for the 3D example.

These samples describe capabilities. Production projects use installed components with user inputs, not this page or its fixture data.
