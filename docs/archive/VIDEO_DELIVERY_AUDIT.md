# 手动视频诊断与旧验收机制

自动声画验收已停用，不再拦截草稿、导出和启动恢复，也不再产生“声画验收未通过，待修复”提醒。历史报告保留，但不作为交付门槛。

仅被旧验收置为待修复、且文件与版本登记完整的项目恢复正常草稿状态；不会自动执行积压任务。正常 HyperFrames 检查、源文件安全校验和导出文件可解码检查继续保留。

## 保留的诊断工具

`runtime/video-audit.py` 是手动诊断工具，可检查质量报告、动画断言、旁白时长与声明区间，以及可选的成片解码、纯色画面和静音指标。运行 `python3 runtime/video-audit.py --help` 查看参数。

这些指标不能证明旁白与画面内容在语义上同步；合法的长纯色镜头、停顿或无声视频也需要结合制作意图判断。诊断结果不可自行恢复为自动交付门槛。

`npm run test:delivery` 覆盖该工具的独立诊断行为；Rust 测试确认已登记的草稿与成片无需通过旧启发式声画验收。制作和恢复要求见 [视频制作流程](../VIDEO_PRODUCTION_WORKFLOW.md)。
