# MotionVid 对照分析与映芽重构方案

分析日期：2026-09-19。该文保留当时的对照分析；用户随后授权实施，当前结果见 [实施记录](MOTIONVID_IMPLEMENTATION.md) 与仓库根目录 design-qa.md。

建议以 MotionVid 的创作入口、风格发现、编辑器布局和操作方式作为下一轮主要参照。
映芽下一步应成为“AI 创作 + 可直接编辑”的视频工作台。已有三个产品视频场景作为使用场景保留，
进入更完整的制作方式和风格体系。

本次使用 Playwright 实际访问 https://motionvid.ai/ 和公开编辑器 https://motionvid.ai/motion-graphics 。

## 本次访问流程和观察

| 步骤 | 实际操作／状态 | 观察及结论 | 范围限制 |
| --- | --- | --- | --- |
| 1 | 首页，指定 9:16，展开更多风格 | 大输入框是中心；制作方式和风格紧邻；指定参数显示成标签，入口清楚 | 尚未提交制作 |
| 2 | 打开 + 菜单 | 素材和设置集中；自动值与明确选择区分，配置负担较低 | 只验证比例选择，没有生成 |
| 3 | 打开全部风格 | 有缩略预览、搜索、类别和选中标记；适合先看效果再选择 | 风格约束是否稳定执行未验证 |
| 4 | 进入编辑器、打开 AI Chat | 窄工具栏、可切换面板、大画布、底部时间线；主要区域稳定 | 公开空状态 |
| 5 | 时间线添加菜单 → 空白镜头 | 统一提供上传、模板、空白、项目 JSON；添加后出现 3 秒镜头和更多工具 | 未验证持久化及复杂项目 |
| 6 | 切换 Media / Templates / Videos | 素材、模板、生成片段都围绕当前画布工作；面板切换不离开项目 | 模板添加触发登录；视频生成未执行 |
| 7 | 切到 390px | 工具栏横向滚动，保留画布和时间线，另有折叠时间线按钮 | 未验证手机触摸拖拽、长片性能及完整键盘可达性 |

可借鉴的核心是任务组织方式。首页不要求先理解大量设置；编辑时同时保留自然语言和手动入口。
风格选择的是跨镜头的视觉方向；模板则是可插入时间线的具体片段，两者需要不同的数据和操作。

可见问题也应记录：桌面 Videos 面板底部控件在当前宽度出现裁切，移动端工具栏有屏外入口；
空白项目里的 Edit / Fonts / Colors 呈不可用状态，但原因不明显。映芽实现时要明确禁用原因，
并保证窄面板控件换行或有清楚的滚动提示。对比度、屏幕阅读器和完整快捷键仍需专门测试。

## 与映芽当前实现的差距

| 维度 | MotionVid 的可见方式 | 映芽当前证据 | 建议改变 |
| --- | --- | --- | --- |
| 首页分类 | Motion Graphics / AI Director / Single Graphic / Edit My Video | `ProductWorkflowPicker` 是产品介绍、发布、讲解 | 新增独立制作方式；原有三项移为使用场景 |
| 风格发现 | 输入框下缩略预览 + 搜索式风格库 | 三条 `ProductExamples` 主要展示同一品牌的场景结构 | 分开风格库、模板库和案例；先做少量真实、差异明确的风格 |
| 输入设置 | + 菜单，Auto，明确选择变标签 | 独立 CreationSettings、画幅和制作模型控件 | 首页与编辑器共用 Composer；设置可固定、可取消固定 |
| 编辑器 | 工具栏 + 切换面板 + 大画布 + 时间线 | AgentWorkspace 对话／预览，ProductStoryboard 位于视频下方 | 以选中镜头／元素为编辑中心，画布高度稳定 |
| 单镜修改 | 提供聊天和手动编辑入口，时间线有剪切等工具 | 新四类按钮经 `sceneRevisionPrompt` 进入 AI 对话 | 确定性的文字、位置、颜色、时长改动直接保存并预览；复杂生成交给 AI |
| 手动修改基础 | 完整程度在登录后需继续核对 | 仓库有 SceneWorkbench 和 `api.editScene` 的标题／效果／聚焦接口，但主工作区未引用该组件 | 复用已有保护和接口，扩展为统一命令与属性面板 |
| 复用 | 模板进入时间线；官方更新还说明跨项目场景复用 | 样片选择主要带入工作流与参考示例 | 保存和插入场景包，连同依赖素材、音轨和字体一起复制 |

## 建议的完整目标

### 首页与发现

导航：发现、我的项目、模板、素材；品牌资料放在独立管理入口。
输入区：一句话／脚本／链接，统一上传入口，制作方式，风格预览，开始制作。
比例、时长、声音、品牌等放在 + 菜单；用户固定的选项显示成标签。

制作方式分为动画视频、单镜动画、编辑已有视频、AI 镜头视频。
四种方式需要不同的执行契约：单镜不能意外拆成多镜，剪辑已有视频须保留源时间和声音，
AI 镜头视频需要独立的生成供应商能力检查。界面按实际可用状态展示，不能让入口暗示未接通的能力。

原有产品介绍、新功能发布、操作讲解保留为场景建议；知识讲解、数据图表、地图等也可进入同一层。
风格初期可覆盖极简产品、杂志叙事、手绘说明、动态图表、字幕强调、地图叙事等方向。
每个风格必须有真实预览、字体和配色规则、运动规则、适用内容和可编辑元素，允许自动选择及不指定风格。
界面沿用映芽名称、Logo、中文文案和原创示例。

### 创作和编辑流程

1. 描述内容或提供素材，选择制作方式和可选风格。
2. 系统提炼要求；可推断项自动处理，只有影响结果且无法推断的事实才提问。
3. 根据任务提供可折叠制作计划；保留“先确认方案”的显式选择，说明需要额外付费的步骤。
4. 逐镜构建，画布和时间线出现真实进展；对话中展示选用素材、关键帧和需要确认的问题。
5. 点选镜头／元素后，属性面板与聊天对象同步。简单修改即时预览，复杂修改生成新版本。
6. 审阅成片，统一导出／分享面板，渲染任务可跟踪，历史版本可查看和恢复。

“自动继续”和“先确认方案”属于新交互设计建议。MotionVid API 的 storyboard 审阅参数有特定
制作模式限制，不能据此断言其所有制作方式都有同样的确认流程。

### 编辑器布局与工具

- 顶栏：项目名称、保存状态、撤销／重做、版本、导出／分享。
- 最左侧：AI 对话、编辑、素材、模板、声音、品牌等工具入口。
- 左侧面板：随工具和当前选择切换；关闭或折叠后让空间给画布。
- 主画布：保持最大可用预览，支持选中元素、拖动与对齐，字幕安全区按需开启。
- 底部：镜头、视频、音频、文字／字幕轨道；支持缩放、折叠、选择、排序、裁切、复制和删除。
- 移动端：画布保持可见，编辑工具用抽屉，时间线可折叠；触摸和键盘均提供替代操作。

仅把现有镜头卡片横向排列，不足以达到这一编辑器目标。需要真实的时间、轨道、元素和撤销模型。

### 底层改造：映芽实现建议，并非对 MotionVid 内部代码的断言

建立统一项目数据：Project → Scenes → Tracks / Clips / Elements，关联素材、源起止、音量、
文字样式、几何变换、时间、字幕、品牌和动画参数。使用稳定 ID 与 revision。

让手动编辑和 AI 编辑走同一组命令：更新文字、变换元素、替换素材、调整时长、移动／复制场景、
修剪片段、设置音量。命令带预期版本、影响范围、撤销信息，修改与版本封存均可审计。
已有 `scene_revision` 的版本与素材保护应复用，并扩展到元素和轨道。

HyperFrames、渲染队列、账号、素材、语音和版本快照可以继续使用。
新增可编辑项目数据到 HyperFrames 的确定性输出层，使属性调整无需模型重新编写整页 HTML。
自定义 HTML 镜头以受管理的独立内容保留，通过声明的可编辑参数接入；不能假定任意 HTML 都可转换成图层。
未声明参数的旧镜头仍支持原有 AI 修改，避免迁移破坏已有作品。

预览、导出和模板复用必须读取同一份项目数据；明确区分修改后的实时预览与旧版 MP4。
这也是服务故障时，用户仍能进行文字、裁切、排版等基础操作的前提。

品牌库、风格库和模板库分别管理：品牌决定自己的资产规范，风格决定表达方式，模板提供可复用场景。
外部 API / MCP 可以在统一编辑命令和任务状态稳定后接入，不需要因此替换现有服务框架。

## 实施顺序与验收

| 批次 | 交付内容 | 可核对的验收结果 |
| --- | --- | --- |
| 1 | 制作方式、共用 Composer、自动／固定设置、风格预览、发现与模板导航 | 选择都进入真实请求；切换页面和重载不丢；模板、风格、使用场景互不混淆 |
| 2 | 编辑器新布局、场景与音轨时间线、选中状态、属性面板、确定性修改 | 改文字／时长／素材无需模型；预览立即更新；撤销、重做、刷新和导出一致 |
| 3 | 场景包复用、品牌管理、素材面板整合、生成工具供应商接入 | 模板可插入已有作品；依赖完整；品牌可重复使用；各模式按真实能力运行 |
| 4 | AI 与手动命令统一、完整版本恢复、渐进预览、导出分享、外部 API / MCP | 手动修改后 AI 能继续且不覆盖未授权内容；同一项目可持续编辑与复用 |

批次是依赖顺序，不是缩小最终范围。最大工作量在可编辑数据、时间线和一致性，其次是风格／模板资产，
首页换布局相对较小。现有能力可迁移，但完整重构不应被估成纯前端换皮。

下一步执行前需补齐登录后参考：已有作品的属性面板、字幕／音频操作、版本切换和导出流程。
可以先实现公开证据充分的部分；对未观察到的细节，应标为映芽设计选择，不能标为一比一复刻。
