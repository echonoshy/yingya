# 映芽产品 UI 设计规范

## 当前方向：桌面印刷影像工作台（2026-09-29）

当前用户已要求把本轮完成的逐页设计与素材实现为桌面 Web App，手机、平板的专门适配和验收延后。桌面设计源为 [22 张桌面稿](../design-previews/yingya-20260929/GALLERY.md)，素材源为 [8 段场景](../design-assets/h3-video-batch-20260929/README.md)与 [10 组应用状态素材](../design-assets/app-state-materials-20260929/COVERAGE.md)。这些素材沿用用户指定的 [Donald Jewkes 动画](https://x.com/donaldjewkes/status/2102801274173587569)的橙发角色与印刷语言，已获本轮用户授权用于后续应用。

采用奶油纸、靛蓝、橙色与少量玫红；桌面顶栏导航、开放作品目录与左右制作分栏。沿用原有小鬼 Logo、实际产品功能、真实作品和用户头像。设计图里的示例数据不能写入真实账户，已有十二个官网示例与来源保留。早期规范保存在 [归档](archive/UI_DESIGN_STYLE_PRE_PRINT.md)。

- 一屏一个视觉重点。首页使用原创新主角与动态场景，工作区是输入与当前作品。
- 奶油纸与靛蓝构成工具界面；橙色用于主操作，玫红用于选中与标题强调。
- 使用原有小鬼轮廓的深蓝版本 `web/public/brand/yingya-ghost-navy.svg`；字体遵循用户更新后的苹果系统字族方向，标题使用半粗体，中文优先苹方
- 不堆叠贴纸、标签、口号、流程卡片或装饰边框。纸纹、胶片纹理只存在于原片，不叠加到正文。
- 图像不承担按钮或文案。交互全部由真实 HTML 控件实现。
- 产品定位遵循 [产品定位](PRODUCT_POSITIONING.md)：从内容、网页和素材制作可讲解、可分享的视频，不承诺生成任意实拍镜头。

## 首页更新：自动播放的灵感之旅（2026-09-29）

用户最新要求首页更丰富、更有转场，并明确视频自动播放、不显示播放或暂停按钮，首页保持展示用途

- 标题与简短介绍在画面上方，居中的六幕视频在下方，随后是介绍与错落的三幅场景，再接页脚
- 2026-09-30：影片保持原生 1344×768，展示最大宽度 1040px、固定 7:4 比例，不拉伸、不按视口裁切；窄屏等比缩小，页面主体最大宽度 1440px
- 原始素材分辨率不等于 4K，不通过插值放大声称新增清晰度；优先限制展示放大与避免二次压缩
- [视觉概念](../design-previews/home-motion-20260929/01-screening.png) 的播放器控件按用户最新指令移除，场景名称横条按 2026-09-30 用户指令彻底删除；[介绍区概念](../design-previews/home-motion-20260929/03-journey.png) 替代未发布的字幕试玩稿
- 新主角保持深蓝短发、橙色贝雷帽与围巾、奶油色外套和相机，与原视频角色独立
- 六幕短片使用本轮原创素材：黄昏城市、光门、海边、列车、相机、屋顶；从原始高码率素材直接用 Remotion 合成套叠画框、门洞穿入、分栏推进、八边快门与六格接片，标题跟随镜头更新
- 视频静音自动循环，无播放器、播放、暂停、拖动或编辑控件；仅在可见时加载/播放，离屏或页面隐藏时自动暂停，重新可见后自动继续
- 减少动效保持静帧并不请求视频；自动播放被浏览器限制或媒体失败时保留插画与正常导航，不遮挡创作入口
- 首页使用本地思源宋体 Heavy 子集与 Bodoni Moda Italic，正文延续系统字体，中文界面不加句号
- 保留原小鬼形象，使用 SVG 颜色滤镜把其原始透明轮廓着为深蓝色，不重画造型；共享品牌入口与 favicon 同步使用 `web/public/brand/yingya-ghost-navy.svg`
- 原始静态小鬼与橙色芽形源文件仍保留，当前产品标志为小鬼；其余界面本轮仅同步身份图标
- 素材位于 `design-assets/home-cinema-20260929`，六幕新版 Remotion 合成位于 `design-assets/home-motion-20260930`，旧版剪辑与参考分析位于 `design-assets/home-motion-20260929`
- 不恢复旧示例节目单，也不引入编辑器、字幕试玩表单或无功能按钮

## 令牌与字体

语义令牌位于 `web/src/styles.css`，工具布局位于 `web/src/print-studio.css`，官网位于 `web/src/marketing/printHome.css`。旧山水与立体片场不再加载。

| --- | --- | --- |
| 画布 | `--canvas` / `--print-paper` | `#f6f3eb` |
| 次级表面 | `--surface` | `#eeebe2` |
| 文字 / 主色 | `--text` / `--primary` / `--print-ink` | `#202e59` |

| 白字主操作背景 | `--action-orange` | `#d54117`（保证小字对比度） |
| 交互强调 | `--accent` | `#bd3165` |
| 链接文字 | `--accent-text` | `#aa2858` |
| 选中 | `--selection` / `--print-peach` | `#f0ded3` |
| 分隔线 | `--line` | `#ded9ce` |
| 强分隔线 | `--line-strong` | `#aaa296` |
| 角色区背景 | 使用素材自身底色 | 不增加界面纹理 |

`--font-ui` 与 `--font-display` 通过 `-apple-system` / `BlinkMacSystemFont` 使用苹果系统字族，中文优先 `PingFang SC`；Windows 与 Linux 分别回退到 Segoe UI / Noto Sans SC。正文 400、操作项 500、标题 600，避免原来的 850–900 超粗字重

`--font-editorial` 使用 `ui-serif`，在支持的苹果浏览器上对应 New York，其他设备回退到 Georgia / 思源宋体，用于少量英文展示文字；`--font-book` 与正文同族；`--font-mono` 使用 `ui-monospace`，随后回退到 SFMono-Regular、Menlo、Consolas。开启光学字号调整，通过系统接口使用字体，不打包苹果字体文件，具体字形由设备提供

字体接入依据：[Apple Fonts](https://developer.apple.com/documentation/technologyoverviews/fonts) 与 [WebKit 系统字体](https://webkit.org/blog/3709/using-the-system-font-in-web-content/)

中文界面标题、标签、说明和状态提示不使用句号，多句说明用分段、逗号或分号衔接；用户输入、方案正文、作品字幕和原始内容保留原有标点，英文标点照常使用

官网桌面标题 90–164px，创作页标题 68–122px，目录页 58–92px。工具正文与导航约 14–18px，辅助文字通常至少 12px。不要把标题字距和字重带入正文。

## 页面结构

### 官网

以本文件「首页更新」节为准，源代码位于 `web/src/marketing`，媒体与首页字族位于 `web/src/assets/home-cinema`

旧场景节目单已移除，旧组件与资料归档在 `docs/archive/pre-cinema-home`，不再进入浏览器依赖图

### 创作、作品、素材与账户

桌面使用横向顶栏，创作、作品、素材三个居中入口；任务与账号在右侧。素材页独立保留文件夹侧栏。手机和平板延续可用基础布局，本轮不重新设计。

桌面创作页左侧为标题与输入框，右侧为橙发角色短片与 Action! 展示文字；下方为真实最近创作或明确标注的示例内容。输入框使用浅色纸面、细边框、小圆角；附件、画幅、模型与生成方案集中在底部。草稿、附件、模型与幂等创建流程保留。

作品使用真实封面与开放目录。素材文件夹在桌面侧栏、手机横向次级栏。搜索、上传、生成素材、重命名、删除和详情继续可用。用量与账单使用同一顶栏、细线表格和数字层级。

### 制作工作台

对话与作品并排：左侧可读会话，右侧浅灰作品区域。方案以浅色单页呈现；视频保持原色。顶部工具紧凑，技术过程按需展开。

- 对话和方案分别滚动；分栏调整支持键盘与持久化。
- 当前任务状态与输入始终容易找到；运行时的排队、立即执行和停止操作保持清楚。
- 方案确认绑定当前检查点与修订；视频反馈绑定版本、时间点或选区。
- 不因换肤重启任务、自动播放作品或丢失输入草稿。
- 手机使用对话、方案、视频切换；软键盘打开后发送仍可见。

### 登录、后台与分享

桌面登录采用左侧靛蓝角色版画、右侧奶油色表单。邀请注册、密码重置和错误提示完整保留。后台采用纸色侧栏与细线数据表；分享页以真实视频为中心，失效状态可读。

用户上传头像与已选预设保持原样，不能为视觉统一覆盖用户身份。

## 动效与素材

- 角色与场景使用本轮已完成的静音视频及静态图。状态素材区分构思、确认、完成、恢复、素材、制作、搜索、音色和排队，不覆盖用户作品。
- 工作台、示例与用户作品不自动播放、不循环，点击或键盘启动一次，支持暂停、继续和重播；公开首页的装饰影片遵循上方首页专节
- 离开视口、隐藏页面、按 Escape 或打开减少动效偏好时暂停。减少动效下不启动装饰片段，并提供文字说明。
- 普通交互沿用共享 160 / 240 / 360ms 时长，输入和状态即时响应。
- 示例视频仅在主动打开后播放。关闭弹窗或页面隐藏时停止，焦点回到触发控件。

## 验收

- 所有操作支持键盘与可见焦点；图标按钮有中文名称，状态不只依赖颜色。
- 文字与图标保证可读对比度；不能以插画遮盖标题、导航或操作。
- 本轮检查 1536×1024（原稿尺寸）、1440×900、1280×800 和 1920×1080 的桌面宽度，长文字、空状态、加载失败与减少动效；手机、平板的专门适配与验收按用户要求延后。
- 图片解码后截图；实际查看截图，不以构建成功代替视觉验收。
- 覆盖首页自动播放与静帧回退、工作台角色播放与暂停、登录注册、创作草稿、作品搜索、素材详情、方案确认、版本与视频反馈、分享、账户和后台。
- 发布前执行 typecheck、web build、单元与相关浏览器测试。发布后核对公共页面脚本/CSS 与发布快照，并在公共前端验证；模拟 API 的检查须明确标注。
