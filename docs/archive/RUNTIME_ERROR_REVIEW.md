# 视频任务运行错误复核（2026-09-14）

范围：复核 Apple 发布会、映芽 3D、图片动态化、网格交易四个项目的任务日志，
并对照另外两个项目中的工具失败。命令失败不等于整次视频任务失败；这里区分
日志中的已发生问题、代码中发现的问题与建议，避免根据文件扩展名判断根因。

## 本次已更新

- 所有启用账号的素材次数不限，配音接口和模型图片工具不再受历史次数限制。
  保留账号权限、停用检查、Token 额度与用量记录。
- 用户统计页、管理用户和邀请表单、列表及 CSV 统一表示“不限次数”。
- 修正运行工具文档中的 Playwright 示例：使用 `.mjs` 的 `import` 与顶层
  `await`，不再混用 CommonJS `require`。修正示例通过 Node 语法检查。
- 工具说明明确使用已安装的 `hyperframes`，不要用 `npx` 找包；说明
  `.yingya/voice.json` 的实际路径及脚本语法和页面初始化的不同检查方式。

## 仍需结构性更新

1. **语音请求统计与重复合成。** `src/tenancy.rs` 的语音入口仍在请求校验和
   合成前调用 `consume_media`，失败也可能增加次数。取消限额后这不会再阻止
   用户，但统计仍不等于成功产物数。建议先校验，再为请求记录独立状态，成功
   后结算；通过请求键和文本、音色、参数指纹复用已有音频。超时结果不明确时
   先对账，不能直接重复生成。验收应覆盖无效输入、服务失败、重复请求、超时
   与断点恢复。不要只用输出文件存在判断音频与当前文案一致。
2. **错误类型与重试策略。** 语音代理目前将多种合成错误映射为 400，脚本再
   抛出通用 Error，Agent 难以选择正确恢复方式。建议提供稳定的错误 code、
   stage、retryable 和 requestId。400/401/403/404 应修输入或配置；429/5xx
   可按服务响应受限退避。合成等操作的重试依赖幂等机制，不能统一自动重试。
3. **共享 JS 运行契约。** 平台已有共享 Node 和发布目录依赖，但 PATH 能找到
   CLI 并不保证项目里的裸 import 能解析同一套包。建议提供稳定的加载入口、
   固定依赖版本和可执行示例，并在真正的用户沙箱中验证。GSAP/Three 等浏览器
   资源与 Node 工具包分开管理；发现项目需要之后再纳入共享清单，不应盲装。
4. **任务状态表达。** `web/src/components/eventTimeline.ts` 当前按非零退出码
   统一标记失败。建议由工具输出结构化结果，区分可选查找无结果、检查发现待改
   内容、可恢复步骤失败和最终任务失败；保留原始退出码与错误详情。不要仅靠
   命令包含 `rg` 等字符串将失败改成成功，组合命令仍可能包含真正故障。

`UNDICI-EHPA` 是代理相关实验性警告，日志中多次与成功命令共存，不能据此认定
任务失败。字体缓存警告同样需要检查实际字体加载和产物；前一版已提供可写
XDG 缓存路径。浏览器也已通过实际启动和 WebGL 探针，不应全局宣布不可用。

推荐顺序：先做语音请求状态与恢复工具，再统一项目校验和 JS 运行模板，最后
基于结构化结果调整任务界面。没有看到反复出现 ESM/CJS 异常的历史日志证据；
本次修正的模块混用是代码复核发现的文档缺陷，不能算作历史任务的已证实根因。
