## 实际落地

- 首页四种制作方式、六种原创风格的真实预览、搜索筛选、自动／固定画幅及可取消标签、统一素材／声音／制作设置。
- 工具栏、切换面板、大画布、选中与直接拖动／缩放、文字／配色／几何／动画属性、图层与轨道；场景排序、切分、复制、删除、音视频源入点和音量；时间线缩放、吸附、折叠。
- 工程 JSON 导入／下载；可撤销的尺寸调整；命令按顺序保存，后端修订冲突保护；持久撤销／重做。
- 项目及个人素材库、含独立依赖的跨项目镜头模板、品牌 Logo／配色／字体保存与应用。
- AI 指令使用同一工程模型，并传递选中镜头／元素及修订。实时工程画布、不可变版本、恢复和实际 MP4 导出／分享；旧 HTML 作品保留原工作区。
- 可选 Runway 适配器提供能力查询、文字／图片生成、持久任务、取消和成片导入。无配置时明确不可用；不伪造结果。MCP 支持固定项目与账号 API 两种模式。
- 视频三类字体随版本打包，预览和渲染使用同一编译输出。
