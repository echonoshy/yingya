# 视频制作流程

制作约定以 [主 Agent skill](../skills/yingya-video-agent/SKILL.md) 及其参考文件为准；
讲解视频使用 [讲解 specialization](../skills/faceless-explainer/SKILL.md)。
本页概述当前流程，具体制作要求随 skill 一起维护。

1. **把内容发展成视频构思。** 区分新建、修改、恢复和只读请求，保留有效成果。新想法或文稿尚无已验证的视觉表达时，按 [创意规划指引](../skills/yingya-video-agent/references/creative-brief.md) 提炼叙事、视觉主体、动作与情绪。完整文稿也需要视觉设计，不默认把段落变成文字卡片。不要求用户先上传素材或填写风格问卷。
2. **确定美术方向、素材路线与镜头。** `.yingya/plan.md` 记录主体造型、材质、光影、色彩、构图、运动特征与制作方式；`scenes.json` 记录每镜看见什么、发生什么变化、如何衔接及素材来源。图片生成可以提供主要画面，程序化动画也可以独立成片。方案与分镜一起审阅。
3. **制作代表性动态片段。** 每种新视觉表达先按 [代表场景指引](../skills/yingya-video-agent/references/representative-scene.md) 制作真实主体素材、动画及必要声音，查看实际构图与运动。不能只靠封面证明全片效果；短片可以直接以第一版完整合成为样本。已有验证的表达和局部修改可复用对应证据。
4. **修正后扩展全片。** 主动生成或制作批准方案需要的素材，沿用通过试做的视觉语言，并随每镜内容变化构图和动作。有旁白时先使用已选音色生成并实测音频，再对齐时间线和字幕；无声视频跳过 TTS。不要在视觉方向尚未验证时批量生成所有素材。
5. **技术检查与审美审阅。** 使用 `hyperframes check --snapshots --json`，检查结构、运行时、布局、动效和对比度。再按 [视觉审阅指引](../skills/yingya-video-agent/references/visual-review.md) 查看实际 MP4 的构图、素材一致性、动画、剪辑与声音，补足各镜头动作和转场证据，修正具体问题。将审阅结果与本版源文件、输出摘要绑定，随草稿封存；技术成功不等于审美已通过。
6. **按影响范围返修。** 画面修改复用旁白，单镜旁白修改只重生成该段及派生字幕/时间偏移，全局音色改变才重做全部旁白；任何实际内容修改仍需验证新合成和渲染新草稿。
7. **确认后导出。** 从确认版本生成高质量成片，检查已有导出以避免重复任务，产物验证成功后才标记完成。

默认仍是方案和草稿两类审核点。显式的用户授权优先，不增加中间确认。
文字分镜允许作为方案材料先行生成；图片分镜、HTML 合成和视频属于方案批准后的制作。

无素材创作可以由图片生成提供主要画面，也可以按内容选择可编辑图解与程序化动画。
上传视频先理解内容，再按目标选择、剪辑、重组和补充；录屏聚焦装配器仅用于适合的镜头，
不作为默认创作路线。工具和组件服务于已选表达，不要求逐个调用或为了数量增加素材。
真实产品、人物、事件与数据需要可靠信息；虚构品牌须明确为虚构。设计参考按当前需要读取，
未安装的外部 Skill 不是可用能力。创意、素材来源及试做结果复用方案与场景文件保存，
不新增 manifest 阶段。代表片段不冒充全片草稿，全片仍需真实渲染与检查。

行为验收覆盖：想法和完整文稿能发展为有主体、动作与素材路线的动画片；授权后主动制作素材并
审阅代表性动态片段；完整 MP4 有具体视觉审阅与修正证据；上传视频可理解、剪辑和补充，
不被强制变成录屏教程；缺少真实产品信息时询问必要事实；局部修改保留已批准设计。
未经制作授权不生成图片、音频或合成文件。文件引用检查不能替代真实 Agent 行为与成片验收，
不得仅凭本流程文档或技术测试声称审美改善已获验证。

## 长命令与自动接续

检查和渲染通过 `runtime/production-task.py` 运行，使用当前请求编号保存任务记录。
命令等待窗口结束时仍保持运行；完整工具结果保留 session ID 和退出码，丢失句柄时可查询任务编号。
报告只在进程成功、JSON 完整且输入未变时原子发布；stderr 独立保存，不能写入检查 JSON。
源文件、依赖、参数和产物摘要匹配时可复用结果，原任务的文件锁阻止重复启动。

模型回合结束后，后端先核对原检查/渲染任务。有新的成功结果且原请求授权完成制作时，
最多自动接续两轮，只补齐原任务内的步骤；接续次数和已消费结果持久保存。
检查或解释请求不启用制作接续，用户停止、等待输入、审核点、实际失败、执行结果未知及无新进展时停止。
服务滚动更新等待当前逻辑任务结束；异常重启后保持原有确认恢复机制，不自动重发不明确的外部请求。
这套机制不增加声画验收门槛，不以空白画面、静音或视觉启发式判定人声不同步。

验证入口：`npm run test:production`（真实子进程、文件锁与原子输出）和
`npm run test:rolling`（模拟模型提前结束、后台等待、接续、停止及版本切换）。
