# 账号头像验收记录

日期：2026-09-21。公开地址：https://yingya.art/app#/。
发布：`20260921-103533-account-avatars`；上一版 `20260921-002535-nine-themes` 保留用于回滚。

## 交付

- 四款预生成头像：奶油猫猫、软软兔兔、小狐狸、熊猫团子。
- 新账号注册立即随机分配；已有账号补齐，选择随账号保存，不随刷新改变。
- 账号菜单的“更换头像”支持选择、随机选择、上传、预览、取消和保存。
- PNG/JPEG/WebP，最大 5 MB、4096×4096；处理照片方向，居中裁切为 256×256 PNG，移除元数据。上传内容只向当前登录账号提供。
- 移除重复齿轮；头像点击加入轻微挤压、摇摆，遵循减少动效设置。
- 保存失败保留选择与预览，可重试；请求 30 秒超时后恢复操作。
