# GSAP 视频参考接入

日期：2026-09-18。参考包 1.0.0，运行脚本 GSAP 3.14.2。

当前发布：`20260918-114358-gsap-skills`，公开入口
`https://yingya.art/app#/`。静态 JS/CSS 与发行版逐字节一致，公开健康检查
报告同一版本。本次没有修改产品前端。

官方 `greensock/gsap-skills` 的 core、timeline、plugins、utils、performance
五份参考固定 commit 后收录在主视频技能内，未安装另一套全局工作流。
`references/gsap/PROVENANCE.json` 保存原始文件路径和 SHA256；完整上游
MIT 许可证保留。主技能和 production 指引按需路由到 GSAP 视频适配说明。

GSAP 核心与 SplitText、DrawSVGPlugin、MorphSVGPlugin、MotionPathPlugin
从 npm 的 3.14.2 tarball 提取，校验 registry 的 SHA512 integrity 并记录
各文件 SHA256。npm 包没有许可证文件，另保存官方标准许可页面；该许可
与 skills 的 MIT 许可分别保留。没有升级原有脚手架的 GSAP 版本。

`scripts/install-gsap.mjs --project PATH --plugins NAME,NAME` 只复制所选
插件、核心、许可和来源到项目的 `assets/gsap-3.14.2`。重复安装可复用相同
内容，发现已有文件改动会拒绝覆盖；不修改项目 HTML，不跟随目标符号链接。
安装器无需联网，不引入运行时 npm 依赖。使用者应保留兼容的既有核心或改为
本地引用，不能加载两份 GSAP。

适配说明以视频时间为准：暂停主时间轴、完成构建后注册、固定字体及画幅、
有限循环、无交互触发和无非种子随机数。明确字体依赖异步初始化必须完成后
再注册，SVG 插件属性是合法动画目标；这也消除了旧 HyperFrames 参考中
“禁止任何异步构建”和“固定属性白名单”的歧义。

参考和资源位于 `skills/yingya-video-agent` 内，沿用不可变发行版快照及租户
递归复制机制。没有更改 Rust API、数据库、用户界面或现有视频的动画引擎。
既有 Anime.js、组件目录与自定义编写路径仍可使用。技能改变产品生成行为，
因此需要发布，并在实际 worker 中验证，不能仅安装到开发者个人目录。

## 验证

- `npm run test:design`：引用闭包、来源哈希、完整资源清单、按需安装、重复
  安装、拒绝覆盖修改、拒绝符号链接目标。
- skill-creator 的 `quick_validate.py`：主 skill 元数据。
- `cargo test installs_bundled`：完整技能目录的递归复制。
- `npm run typecheck` 和 `npm run web:build`：现有应用构建。
- `npm run test:gsap:video -- /tmp/yingya-gsap-qa/local`：三组人工编写的
  6 秒验收场景，验证真实插件、中文错峰、SVG 路径、形状变换，以及倒退、
  重复、重新加载直接定位的像素一致性。
- 对上述场景执行 HyperFrames check（含 snapshots、motion、contrast）及
  MP4 render，并检查实际 MP4 抽帧和元数据。
- 公开网站用隔离测试账号运行同题接入前/后任务，读取实际生成源文件、
  检查报告、最终草稿和 worker 资源版本。人工样片不能当作自动生成改善
  的证据；运行结果与限制在交付时单独报告。

本机验收材料位于 `/tmp/yingya-gsap-qa/`，不进入运行资源。复现样片使用
`tests/gsap-video.mjs`，不包含账号或凭据。无需启动或重启开发服务器。

## 实际结果与边界

已通过六项资源/安装检查、主技能格式校验、租户技能递归复制测试、Rust 格式
与 lint、类型检查与发行版构建。三个独立人工样片均完成 check 与 MP4 导出：每段 6 秒、
1280×720、30fps、无音轨，每段 121 个运动采样；倒退、重复和重新加载后
直接定位的截图完全一致。实际 MP4 已抽帧审阅。

公开网站上的受控生成任务已实际读取 GSAP 适配指南，成功运行离线安装器，
并在源码中注册和使用全部四个插件。生成了 12 秒、1280×720、30fps 静音
草稿，包含可编辑中文标题、SVG 连线与路径运动、圆形和菱形变换。它修正了
描边出现顺序断言和辅助路径显示，最终统一检查通过，包含 241 个运动
采样。公开草稿文件可访问，桌面 1440×1050 与窄屏 390×844 页面无 JS 错误。
验收生成在首版 `20260918-111433-gsap-skills` 的不可变 worker 上完成；最终版
保留相同插件和上游参考，增加了安装器帮助命令及定位验证方法的说明。

最终草稿为 `draft-3`；网站任务已结束并进入 `draft_review`。测试 worker 随后
自然切换到最终发行版，46 个技能文件与发行版逐字节一致，租户安装器的
`--help` 返回成功。最终服务状态：

另外对最终生成源码进行了独立浏览器定位验证，覆盖 11 个时刻的倒退/重复

明确要求定位实时 composition timeline；重复提取编码后 MP4 的同一帧不能
证明动画源码的定位一致性。

接入前同内容对照使用了既有 Anime.js 路径，也成功交付。接入后验收明确指定
GSAP 四插件，因此这次验证的是接通与实际可用性，不是严格的质量、耗时或
成本 A/B 实验，不能据此承诺整体创意提升或成本下降。
