# 映芽产品 UI 设计规范

本文档是映芽 Web 产品界面的设计依据。产品采用 Apple 风格的清晰、克制与直接，
并将其转化为适合中文 AI 视频制作工作台的界面语言。

Apple 只作为设计原则参考。界面必须保留映芽名称、Logo、中文产品语气、视频制作
概念和原创资产，不复制 Apple 的商标、插画、产品图或专有系统控件。

## 产品表达

产品定位遵循 [产品定位](PRODUCT_POSITIONING.md)：映芽是对话式动画视频制作工作台。
起始页用文案、网页和素材作为输入引导，突出产品演示、知识动画、数据故事和品牌短片。
说明“确认方案 → 预览与修改 → 导出成片”的工作方式；使用具体的文字、画面和节奏修改示例。
不承诺凭描述生成任意实拍镜头，也不把图片生成等素材能力说成视频生成模型。
HyperFrames 是制作底座；普通创作入口优先讲用户能完成的作品与操作。

## 设计方向

映芽采用“明亮的影像工作室”视觉方向：纸白画布、低彩度雾灰表面、石墨文字与精确的系统蓝反馈。
中文阅读与真实影像共同构成识别感，普通操作不使用开发工具式的等宽排版。导航退后，当前任务、对话和视频产物
成为主角。设计遵循以下原则：

1. **清晰第一。** 每一屏有明确焦点，标题、正文、状态与操作层级一眼可辨。
2. **内容优先。** 白色主画布承载创作内容，侧栏与检查器使用浅灰背景退居其次。
3. **直接操作。** 按钮描述结果，选中状态贴近对象，反馈及时且不打断流程。
4. **克制层次。** 优先使用留白、对齐、字号和细分隔线，只在浮层使用阴影。
5. **状态可理解。** Agent 的运行、等待、完成、中断与失败均同时使用文字和图标。
6. **输入始终可用。** 工作时仍能继续输入，并清楚选择排队或立即应用。

## 设计令牌

所有界面复用 `web/src/styles.css` 中的语义 token。历史 `--prey-*` 和
`--purple-*` 只作为兼容别名，不应在新组件中继续扩展。

| 角色 | Token | 建议值 | 用途 |
| --- | --- | --- | --- |
| 主画布 | `--canvas` | `#ffffff` | 对话、编辑与主要内容 |
| 应用背景 | `--background` | `#f3f4f6` | 导航、检查器和页面底色 |
| 抬升表面 | `--surface` | `#fafafb` | 控件、输入区和内容容器 |
| 悬停表面 | `--surface-hover` | `#e9ebef` | 悬停和弱选中 |
| 主文字 | `--text` | `#24262b` | 标题、正文和主操作 |
| 次文字 | `--muted` | `#50545c` | 说明和次级信息 |
| 弱文字 | `--dim` | `#626771` | 元数据和占位符 |
| 分隔线 | `--line` | `#e0e3e8` | 面板边界与分组 |
| 主操作 | `--primary` | `#24262b` | 创建、确认、发送 |
| 强调文字 | `--accent-text` | `#005fc1` | 灰色表面上的链接、状态文字 |
| 系统强调 | `--accent` | `#006bd6` | 焦点、链接、选中和运行状态 |
| 危险 | `--danger` | `#d70015` | 错误和破坏性操作 |
| 警告 | `--warning` | `#a05a00` | 待确认和注意事项 |

同一屏幕只使用一个强调色。系统蓝表达交互或实时状态，不作为大面积背景。

新增交互表面：`--selection`（`#edf3ff`）承载选中控件，`--selection-line`（`#c3d5f3`）标记选中边界；`--surface-inset`（`#eceef1`）用于预览外框与控件轨道。浅蓝仅用于交互状态，白色仍是工作画布。

## 字体与文字

- 中文界面使用 `--font-ui`，优先系统无衬线字体与 Noto Sans SC 回退。
- 等宽字体 `--font-mono` 仅用于代码、精确时间码和技术路径；模型选择、画幅选择、版本选择、状态与日期使用界面字体。数字用 `font-variant-numeric: tabular-nums` 保持对齐。
- 字号必须复用语义 token：`--text-display` 首页标题 32-40 px、`--text-title` 页面标题 22 px、`--text-section` 工作区标题 18 px、`--text-body` 阅读正文 15 px、`--text-control` 常用控件 13 px、`--text-caption` 辅助信息 12 px。
- 输入使用 `--text-input` 16 px，避免窄屏输入过小；极窄工具栏允许 12 px 控件。字重限定为正文 400、控件 500、标题/选中 600，Logo 可保持 700。
- 搜索框统一使用 `--text-search`：桌面跟随 `--text-control`（13 px），800 px 以下跟随 `--text-input`（16 px）；提示文字与输入文字保持同字号，不缩小点击区域。
- 中文阅读正文行高 1.8，控件与说明行高 1.5-1.65。中文工作区标题不压缩字距；仅首页展示型标题允许 -0.02em。
- 文案简洁、具体，优先“动作 + 对象”，例如 `生成脚本`、`确认并制作`。
- 不使用装饰性大写标签、拟人闲聊、虚假精度和无解释的英文。

## 形状、边界与阴影

- 8 px：紧凑图标容器。
- 12 px：按钮、输入、标签和列表行。
- 18 px：主要输入区、预览和检查点。
- 全圆胶囊仅用于确实需要的短状态或分段控件。
- 相邻面板用 1 px 系统灰分隔线区分。
- 普通内容不使用悬浮卡片阴影。阴影仅用于菜单、模态框和固定输入浮层。
- 按钮按下可下移 1 px 或缩放至 0.98；不使用发光、弹跳或大范围旋转。

## 产品布局

### 桌面工作区

- 默认使用“创作对话 / 作品画布”两区，作品画布内的素材检查器按可用空间展开。
- 对话区默认约 620 px，可通过鼠标和键盘调整并记住宽度；最大 960 px，并为右侧保留至少 400 px，窄屏使用标签切换。
- 账号入口位于首页与素材工坊侧栏底部，点击展开用量统计与退出操作；窄屏收敛为顶部账号图标。进入项目制作页后隐藏账号入口，制作页使用完整视口高度。
- 画布宽度不足 850 px 时折叠素材检查器，素材仍可从标签与输入区选择。
- 视频按宽高比与画布可用宽高适配，不使用会重复压缩竖屏视频的百分比。
- 顶栏约 76 px，展示项目身份、任务主状态和导出入口。导出入口定位并聚焦设置。
- 需求阶段显示要求摘要，方案待确认阶段直接呈现方案，草稿阶段以视频为主要内容。
- 草稿版本、源文件变更与导出状态分别说明；不能把尚未完成的草稿称为成片。

### 起始页

起始页使用一个简短主标题、辅助说明、大型输入区和少量起始建议。取消暗色环境网格、
光球、发光和漂浮 Agent 标签。输入是明确的创作入口；最近作品使用真实视频封面与名称、状态、更新时间，方便继续创作。
项目分为制作中、待处理、可导出、已导出、待恢复。已有视频不要求对话确认；已导出依据当前视频版本的导出记录，源文件有更新时单独提示。

### 窄屏与移动端

小于 800 px 时，导航收敛为顶部工具栏；对话、产物和预览使用明确标签切换。对话输入区
保持可见，预览页提供直接描述修改的入口，不能遮挡内容。最低支持 320 px，并重点检查 390 px。

## 组件行为

### 项目导航

- 默认列表透明，悬停使用更深一级系统灰。
- 选中项使用白色表面、1 px 边框和轻微阴影，不使用彩色背景。
- 运行中项目同时使用系统蓝状态点和文字标签。
- `新建视频` 是左栏唯一占主导的深色实心按钮。
- 删除操作在悬停、键盘聚焦和触摸场景中均可发现。

### 输入区

- 使用白色表面、1 px 边框和 18 px 圆角。
- 聚焦时显示 2 px 系统蓝焦点环，不上浮、不发光。
- 附件和上下文以可移除标签进入输入流。
- 上传、模型、音色、画幅、排队、停止和发送保持稳定位置。
- 工作区输入框将附件与素材归为资源组，将音色、模型和发送归为提交组。宽度足够时同排，空间不足时提交组整体换行，发送不能单独换行。
- 正在运行时，新消息默认排队；发送后可在排队消息上点击“立即执行”，中断当前任务并优先处理该条消息。停止按钮与发送按钮相邻，保留独立操作。
- 制作页使用紧凑字号：桌面对话正文、输入与产物搜索采用 `--text-control`，素材、音色和模型控件采用 `--text-caption`；移动端输入与搜索保持 `--text-input`。
- 发送按钮使用近黑底白字；禁用时降低对比度并禁止点击。

### Agent 活动与检查点

- Agent 活动按时间排序，完成的技术操作折叠成摘要。
- 运行中显示进度图标和现在进行时动作，完成显示勾选和结果摘要。
- 脚本／制作方案检查点保留人工审阅，使用抬升的浅灰表面、清晰标题与一个主决定。
- 视频草稿生成后，对话不再显示重复的确认卡片；用户在预览区审阅，通过导出面板渲染成片。
- 授权用琥珀色语义，失败和破坏性决定使用红色语义。

### 作品画布

- 画布使用浅灰背景，媒体预览使用近黑舞台，避免给视频内容叠加品牌色。
- 分段控件区分预览与产物：画布标签使用滑动蓝色下划线，移动端与项目筛选使用浅蓝选中表面，始终保留文字和选中语义。
- 文件名、路径、版本与检查状态应在不打开调试信息时可见。
- 工作台仅提供预览、素材和产物标签，不提供独立分镜编辑入口。
- 修改以对话为主，用户可以描述具体时间段，也可以从预览添加时间点或画面标注。
- 视频控制与时间反馈保持紧凑，选中项使用边框和文字双重表达。

## 动效

动效强度保持低到中等，仅用于状态变化和直接反馈：

- 焦点、悬停、按下、选择和展开使用同一组时长 token；状态与输入立即更新，动效只承接视觉变化。
- 保留既有布局，以“快响应、缓收尾”统一操作手感。快速反馈 160 ms，标准切换 240 ms，面板进入 360 ms；进入使用减速曲线，退出使用加速曲线。
- 筛选与标签的选中标记在原位滑动；快速连续操作从当前画面接续，调整窗口后重新对齐。
- 作品出现依次延迟 28 ms，最多累计 140 ms；封面悬停轻微放大，操作提示淡入，键盘聚焦也能发现入口。触摸设备不依赖悬停。
- 模态框短距离淡入，关闭时快速收起；任务面板与菜单共用可中断开合，动画不延迟状态更新与输入。
- 新视频载入时短暂淡入；不因装饰动效重新加载视频、自动播放或改变播放位置。
- 允许 4-8 px 短距离淡入、面板滑入、按钮按下和运行状态脉冲。
- 禁止持续环境动画、装饰性漂浮、发光扫描、旋转按钮和大幅弹跳。
- `prefers-reduced-motion: reduce` 下关闭非必要动画与平滑滚动。

## 无障碍与质量门槛

- 所有控件支持键盘，并显示清晰的 2 px 焦点环。
- 纯图标按钮具有中文无障碍名称和适当的 `title`。
- 文字与图标达到 WCAG AA；占位符和弱文字也需保持可读。
- 状态至少使用文字、图标、形状中的两种，不只依赖颜色。
- 中文、长路径、长项目名与模型名必须有明确的截断或换行策略。
- 测试桌面三栏、面板调整、390 px、320 px 和减少动效模式。
- 前端改动后运行 `npm run typecheck`、`npm run web:build`、相关 UI 测试，
  并按照本文规范进行桌面与移动端截图检查。

### 文件与浮层

- 图片、视频、音频、文档分别预览；未知二进制提供下载，不按文本读取。
- 对话中的项目文件链接必须通过项目文件 API 解析，不能跳到文件系统形状的页面路由。
- 音色选择与创建使用有边界的对话框；模型菜单根据可用空间展开并支持键盘导航。
- 素材分类只切换列表；移动端点击具体素材后才打开详情。
- 素材详情保留预览、基本信息、文件夹、重命名、删除与下载；素材在项目对话中选择，不展示使用位置和项目分配控件。
