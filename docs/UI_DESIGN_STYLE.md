# 映芽产品 UI 设计规范

本文档是映芽 Web 产品界面的设计依据。产品采用 Apple 风格的清晰、克制与直接，
并将其转化为适合中文 AI 视频制作工作台的界面语言。

Apple 只作为设计原则参考。界面必须保留映芽名称、Logo、中文产品语气、视频制作
概念和原创资产，不复制 Apple 的商标、插画、产品图或专有系统控件。

## 设计方向

映芽应像一张明亮、安静且可信赖的创作台。导航退后，当前任务、对话和视频产物
成为主角。设计遵循以下原则：

1. **清晰第一。** 每一屏有明确焦点，标题、正文、状态与操作层级一眼可辨。
2. **内容优先。** 白色主画布承载创作内容，侧栏与检查器使用浅灰背景退居其次。
3. **直接操作。** 按钮描述结果，选中状态贴近对象，反馈及时且不打断流程。
4. **克制层次。** 优先使用留白、对齐、字号和细分隔线，只在浮层使用阴影。
5. **状态可理解。** Agent 的运行、等待、完成、中断与失败均同时使用文字和图标。
6. **输入始终可用。** 工作时仍能继续输入，并清楚选择排队或立即应用。

## 设计令牌

所有界面复用 `web/src/styles.css` 中的语义 token。历史 `--prey-*` 和
`--purple-*` 只作为兼容别名，不应在新组件中继续扩展。

| 角色 | Token | 建议值 | 用途 |
| --- | --- | --- | --- |
| 主画布 | `--canvas` | `#ffffff` | 对话、编辑与主要内容 |
| 应用背景 | `--background` | `#f5f5f7` | 导航、检查器和页面底色 |
| 抬升表面 | `--surface` | `#fbfbfd` | 控件、输入区和内容容器 |
| 悬停表面 | `--surface-hover` | `#e8e8ed` | 悬停和弱选中 |
| 主文字 | `--text` | `#1d1d1f` | 标题、正文和主操作 |
| 次文字 | `--muted` | `#424245` | 说明和次级信息 |
| 弱文字 | `--dim` | `#6e6e73` | 元数据和占位符 |
| 分隔线 | `--line` | `#d2d2d7` | 面板边界与分组 |
| 主操作 | `--primary` | `#1d1d1f` | 创建、确认、发送 |
| 系统强调 | `--accent` | `#0071e3` | 焦点、链接、选中和运行状态 |
| 危险 | `--danger` | `#d70015` | 错误和破坏性操作 |
| 警告 | `--warning` | `#a05a00` | 待确认和注意事项 |

同一屏幕只使用一个强调色。系统蓝表达交互或实时状态，不作为大面积背景。

## 字体与文字

- 中文界面使用 `--font-ui`，优先系统无衬线字体与 Noto Sans SC 回退。
- 技术路径、时间、画幅与模型名使用 `--font-mono`。
- 主标题 28-48 px，工作区标题 17-21 px，正文 14-17 px，元数据 11-12 px。
- 中文正文行高 1.55-1.75。仅展示型标题允许轻微负字距。
- 文案简洁、具体，优先“动作 + 对象”，例如 `生成分镜`、`确认并制作`。
- 不使用装饰性大写标签、拟人闲聊、虚假精度和无解释的英文。

## 形状、边界与阴影

- 8 px：紧凑图标容器。
- 12 px：按钮、输入、标签和列表行。
- 18 px：主要输入区、预览和检查点。
- 全圆胶囊仅用于确实需要的短状态或分段控件。
- 相邻面板用 1 px 系统灰分隔线区分。
- 普通内容不使用悬浮卡片阴影。阴影仅用于菜单、模态框和固定输入浮层。
- 按钮按下可下移 1 px 或缩放至 0.98；不使用发光、弹跳或大范围旋转。

## 产品布局

### 桌面工作区

```text
┌──────────────────┬──────────────────────────────┬──────────────────────┐
│ 项目与导航       │ 对话 / Agent 工作            │ 作品画布 / 产物       │
│ 232-276 px       │ 最小 440 px，占剩余空间       │ 约 390-440 px         │
│ 浅灰背景         │ 白色主画布                    │ 浅灰背景               │
└──────────────────┴──────────────────────────────┴──────────────────────┘
```

- 顶栏高度 72-76 px，承载项目身份、实时状态和高价值操作。
- 左栏是导航，不是数据看板。选中项目使用白色表面和安静边框。
- 中央列承载对话、Agent 活动、检查点、队列和底部输入区。
- 右侧画布显示预览与项目产物，可关闭、可调整宽度。
- 面板调整器支持鼠标和键盘，并持久化宽度。

### 起始页

起始页使用一个简短主标题、辅助说明、大型输入区和少量起始建议。取消暗色环境网格、
光球、发光和漂浮 Agent 标签。项目列表始终可见，输入是第一视觉焦点。

### 窄屏与移动端

小于 800 px 时，导航收敛为顶部工具栏；对话、产物和预览使用明确标签切换。输入区
固定在当前视图底部但不能遮挡内容。最低支持 320 px，并重点检查 390 px。

## 组件行为

### 项目导航

- 默认列表透明，悬停使用更深一级系统灰。
- 选中项使用白色表面、1 px 边框和轻微阴影，不使用彩色背景。
- 运行中项目同时使用系统蓝状态点和文字标签。
- `新建视频` 是左栏唯一占主导的深色实心按钮。
- 删除操作在悬停、键盘聚焦和触摸场景中均可发现。

### 输入区

- 使用白色表面、1 px 边框和 18 px 圆角。
- 聚焦时显示 2 px 系统蓝焦点环，不上浮、不发光。
- 附件和上下文以可移除标签进入输入流。
- 上传、模型、音色、画幅、排队、停止和发送保持稳定位置。
- 发送按钮使用近黑底白字；禁用时降低对比度并禁止点击。

### Agent 活动与检查点

- Agent 活动按时间排序，完成的技术操作折叠成摘要。
- 运行中显示进度图标和现在进行时动作，完成显示勾选和结果摘要。
- 检查点使用抬升的浅灰表面、清晰标题、简短后果说明与一个主决定。
- 授权用琥珀色语义，失败和破坏性决定使用红色语义。

### 作品画布

- 画布使用浅灰背景，媒体预览使用近黑舞台，避免给视频内容叠加品牌色。
- 分段控件区分预览与产物，选中项使用近黑底白字。
- 文件名、路径、版本与检查状态应在不打开调试信息时可见。
- 视频控制、分镜列表与时间反馈保持紧凑，选中项使用边框和文字双重表达。

## 动效

动效强度保持低到中等，仅用于状态变化和直接反馈：

- 快速反馈 150 ms，标准切换 220 ms，面板进入 320 ms。
- 允许 4-8 px 短距离淡入、面板滑入、按钮按下和运行状态脉冲。
- 禁止持续环境动画、装饰性漂浮、发光扫描、旋转按钮和大幅弹跳。
- `prefers-reduced-motion: reduce` 下关闭非必要动画与平滑滚动。

## 无障碍与质量门槛

- 所有控件支持键盘，并显示清晰的 2 px 焦点环。
- 纯图标按钮具有中文无障碍名称和适当的 `title`。
- 文字与图标达到 WCAG AA；占位符和弱文字也需保持可读。
- 状态至少使用文字、图标、形状中的两种，不只依赖颜色。
- 中文、长路径、长项目名与模型名必须有明确的截断或换行策略。
- 测试桌面三栏、面板调整、390 px、320 px 和减少动效模式。
- 前端改动后运行 `npm run typecheck`、`npm run web:build`、相关 UI 测试，
  并按照本文规范进行桌面与移动端截图检查。
