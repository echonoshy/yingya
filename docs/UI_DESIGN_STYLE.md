# 映芽产品 UI 设计规范

## 账号入口与二级菜单（2026-10-07）

- 导航中的账号入口只显示已有头像，44px 触达区域；邮箱与账号身份放在展开菜单顶部。
- 一级菜单保留「使用情况」「设置」「帮助」「退出登录」。用量统计与 API 等价账单归入使用情况，更换头像与管理员的账号管理归入设置，版本记录与联系管理员归入帮助。
- 鼠标悬停一级菜单即在旁边展开二级选项，移入二级菜单保持展开，靠近屏幕边缘时向另一侧打开，空间不足时在菜单内展开。悬停不移动键盘焦点；点击、键盘与触屏仍可进入带返回入口的二级页面。
- Escape 先返回上一级，再关闭并恢复头像焦点。点击外部或焦点离开时关闭，窄屏浮层保持在视口内，不遮住右上角任务入口。

## 任务入口与文字层级（2026-10-07）

- 任务入口使用右上角固定的 44px 铃铛按钮，只显示图标；未读更新用圆点和屏幕阅读器提示，悬停显示「任务中心」。与头像错开，窄屏不遮挡标题，弹层保留外部点击、Escape 关闭和焦点恢复。
- 中英文正文统一优先使用已加载的 Noto Sans SC Variable；固定展示标题沿用展示字体，手写短句与代码标签只用于原有位置。
- 工作控件与表单标签使用 14px，正文 15px，输入文字不低于 14px（手机输入 16px），辅助信息 12px，面板标题 16px。常规/中等/强调字重为 400/500/600；控件行高 1.5，辅助文字 1.6，正文 1.75。复用 `styles.css` 的文字令牌，不在同类控件上另定字号或行高。
- 文字筛选复用 24px／20px 间隔；320px 创作起点使用两列布局，避免不齐整的三加一换行。弹窗与列表保留清晰的标题、说明、操作层级。

## 创作输入与上传反馈（2026-10-06）

- 移除创作设置面板。创作工具条只保留素材、参考时长、画幅与模型；时长默认约 30 秒，可调整，明确描述与真实素材决定最终方案时长。
- 字幕、配乐、音频处理、受众和视觉要求交给创作描述与方案，不预设 120 秒、中文字幕或旁白。旁白音色在「添加素材」内选择，音色偏好不强制添加旁白。
- 上传按文件显示真实字节进度，并区分等待、传输、服务器保存、完成与失败。成功项即时可用，失败项可重试，不能因单项失败掩盖已完成的素材。创作附件暂存浏览器时明确提示「提交时上传」。

## 目录代码装饰（2026-10-06）

项目与素材目录沿用创作页的代码标签：标题前分别显示 `<Projects>`、`<Assets>`，内容后显示对应闭合标签；共用等宽字体、蓝色文字与灰色括号。标签为静态装饰，不接受点击、不进入屏幕阅读器，不在单张项目或素材卡片上重复叠加。

## 控件与空状态追加规范（2026-10-06）

- 产品界面移除字符伙伴、emoji 表情与对应装饰影片；空白、加载、失败和分享状态用简短文字与必要操作表达。用户头像、素材、视频和功能图标保留。
- 普通下拉统一使用 `SelectControl`：细边框、6px 圆角、40px 触达高度，菜单白底、蓝色选中、独立箭头与勾选。支持键盘、长名称、窄屏与弹窗内选择；模型等复合菜单沿用相同令牌。
- 同级空状态共用标题、说明、操作的字号、行高和起始位置；切换素材来源时保持排版稳定。文字筛选不叠加按钮阴影，同行整理控件统一 40px 高度。
- 下拉和浮层菜单点击外部、焦点离开或按 Esc 时收起；Esc 关闭恢复触发控件焦点，菜单内操作照常完成。
- 素材可拖到文件夹或「未整理」，批量选中后拖动任一选中素材即可一起移动。目标以虚线、蓝色和「移入」文字反馈；失败项保留选中重试，键盘与触屏继续使用批量整理。
- 文字筛选 tab 桌面间隔 24px、窄屏 20px；分段切换控件保留紧凑分组和足够内边距。素材来源不再挤在一起，素材类型补充「其他」文件分类。

## 首页视频陈列与轻量加载（2026-10-06）

首页首屏将创作准备与宣传片合并：桌面左侧是字形标题和紧凑的准备表单，右侧是更大的完整 16:9 影片，画布最大 1440px。900px 以下依次为标题、准备、影片，优先让“准备创作”可见。影片以深色薄边、阴影和蓝色偏移线框强调画面，保留 YingYa 英文字标、标题字形互动和少量代码元素；去掉重复宣传片入口、第二组标题与播放说明。

创作从“参考视频 / 复刻网站 / 剧本 / 风格”四个起点进入，提示提供具体链接、故事和画面方向，而非只输入一句话。“准备创作”只带着选择和原输入进入工作室，登录后追加到已有草稿，不自动生成。工作室提供背景音乐、参考图和参考视频上传，以及素材库和内置大纲／视频风格入口；剧本与大纲直接填写在文本框，参考文件默认为“仅供参考”。可先生成参考图、预览并选入本次创作，再生成图文方案。纯文字方案收起为补充信息，优先审阅关键画面，确认方向后制作；这些起点可组合，不要求全部提供。

九支示例新增“云间列车（Cloud Express）”。参考区采用大小错落的双列画面与细描边，桌面最后三支组成等宽尾排；平板双列并让末支横跨两列，手机单列；保留实际封面、中英文标题和时长，不叠加大播放键；标题旁的小箭头提示打开，悬停预览时变为静音图标。鼠标停留后只加载当前一支静音循环预览，离开立即卸载；点击打开原生模态并播放原音轨，支持前后切换与关闭后焦点恢复。“用这个风格准备创作”将真实视频链接追加到草稿，选中参考入口并聚焦输入，不提交任务。

主宣传片使用从原始 4K 素材导出的 2560×1440、60fps 版本，约 5.8 MB，封面为 2560px；九支示例保持 1080p、30fps。每支只有一个版本，不提供清晰度选择。示例封面懒加载，影片只在悬停或打开时加载；主宣传片进入可见区域后静音自动循环。减少动效时保留封面并从底部控件手动播放，悬停不触发视频。播放条采用画面内深色渐变与白色控件；桌面鼠标离开画面立即隐藏，不受鼠标点击后保留的焦点或暂停状态影响；悬停或键盘聚焦恢复，触屏始终可操作。支持暂停、进度、重播、声音、全屏和失败重试；浏览器阻止有声播放时显示主动开启声音的操作。

悬停预览和参考弹窗暂时暂停主片，离开或关闭后恢复可见主片原有的播放意图，不覆盖用户手动暂停。离屏和隐藏页面暂停，任何时刻最多播放一支。所有网页视频使用 H.264/AAC 与 faststart，资源及来源摘要在 `web/src/assets/showcase`，处理脚本为 `scripts/prepare-home-media.py`。源素材不进入页面资源或发布包。

## 当前视觉与品牌

沿用黑白字形画布、蓝色定位与选中态、开放布局和清楚的中文操作。官网、登录、工作室导航、管理与分享统一使用 `YingYa` 粗体字标和橙色圆点，浏览器图标为 `web/public/brand/yingya-monogram.svg`。用户头像、作品和上传素材保持原样。

- 一屏一个重点，不堆叠贴纸、口号、装饰边框或重复的功能卡片。
- 正文与控件清楚可读；固定标题和短引导语可以变化字形，不把展示字体用于用户内容。
- 实际操作使用已有 Phosphor 图标；界面不使用 emoji、字符伙伴或旧角色影片。
- 设计预览和测试数据不写入真实账户，状态不伪造进度。
- 控件反馈约 120–180ms，面板切换约 200–300ms；减少动效时保持内容、焦点和操作完整。
- 产品定位遵循 [产品定位](PRODUCT_POSITIONING.md)，页面任务和全产品检查范围见下方覆盖矩阵。

## 前端开发方法（参考 Anthropic，2026-09-30）

项目设计规范采用用户指定的 Anthropic 官方 [frontend-design/SKILL.md](https://github.com/anthropics/claude-code/blob/dbdd79cebfae5891f5b0fab6f7773ea520d289a7/plugins/frontend-design/skills/frontend-design/SKILL.md)（固定提交 `dbdd79cebfae5891f5b0fab6f7773ea520d289a7`，2026-09-30 核对）。以下是项目执行规则，覆盖全部产品页面、弹窗及状态；客户视频继续遵循各自设计契约。

采用的原则：从真实任务出发，先规划再实现；建立清楚的排版层级；让装饰与动效表达信息；文案说明操作及结果；通过截图和实际交互复查。用户明确的视觉要求优先。

### 在映芽中的执行方式

1. **先明确当前任务。** 新页面或明显改版，用几句话说明使用者要完成什么、主要操作在哪里、复用哪些令牌与组件；复杂布局可附简图。模型菜单、标签等小改动只需说明影响范围，直接沿用现有布局。
2. **沿用已确认的设计。** 遵循本文件的黑白字形、蓝色定位和 YingYa 字标。字体按下方分工使用：固定标题和短句可以变化字形，用户内容与工作控件维持清晰；沿用已有字体依赖，新增静态字形子集按需加载。
3. **按工作内容组织界面。** 创作页围绕输入和生成方案；作品页围绕封面与打开作品；素材页围绕查找与选择素材；工作台围绕对话、当前任务及方案或视频。新内容进入相应区域，避免再叠加重复的介绍区。
4. **检查每个额外元素的用途。** 编号用于真实步骤，边框用于分组或交互边界，状态文字与图标表达含义。不要为凑版式增加英文眉题、口号、渐变、同形卡片或重复箭头；现有 Phosphor 操作图标按功能保留。
5. **保持中文操作一致。** 例如“保存名称”成功后提示“名称已保存”；“生成方案”和“导出视频”分别描述实际行为。空作品列表提供“开始创作”，搜索无结果提供清除筛选；请求失败保留已输入内容，并给出可执行的恢复方式。示例只用于测试，不写入真实用户数据。
6. **控制改动范围。** 优先调整现有组件与对应样式文件；页面样式限定在所属容器或组件类名下，不通过反复追加全局选择器、提高权重或 `!important` 覆盖旧规则。发现冲突时修正原规则，并检查共享组件在其他页面的表现。
7. **动效服务于反馈。** 复用现有展开、关闭和状态切换机制，输入与提交反馈及时出现。装饰影片继续遵守下文的可见性、静音和减少动效规则；普通修复不额外引入动画库。
8. **实现后检查真实状态。** 按本文件验收要求查看截图，并操作本次涉及的流程；包含窄屏、键盘焦点、加载、空状态与失败恢复。调整视觉不能丢失草稿、改变任务确认流程或破坏真实 API 调用。报告简述改动、验证结果与未验证项。

### 必须逐项检查的设计规则

- **排版承担层级。** 展示标题按明确角色搭配粗黑字、活泼展示字与手写短句，表单、正文和数据使用可读的常规字重。不要随意给标题中的单个词换色、加斜体，不增加全大写英文眉题。正文通常控制在 40 个汉字或 80 个拉丁字符以内的行宽；表格与代码使用独立滚动容器。
- **每个结构都有含义。** 编号只表达真实顺序；边框区分分组和操作边界。导航、筛选、插入示例和提交操作要有区别，不在每个按钮末尾机械附加箭头。
- **一屏只保留一个视觉重点。** 工具页以当前任务为重点；既有角色插画可以保留，不能挤掉输入、试听和恢复操作。辅助状态写清操作与去向，不重复营销口号。
- **不同设备拥有相同能力。** 窄屏允许分栏变纵向、表格局部滚动，不能隐藏试听、提交或关键管理操作。按钮触达区原则上至少 40px，主要操作至少 44px；键盘焦点要明显。
- **弹窗复用原生模态。** 优先使用 `ActionDialog` / `EditorDialog`，验证焦点限制在弹窗内、Escape 关闭、关闭后恢复到触发控件，内部菜单关闭时不能连带关闭弹窗。
- **失败和空白给出下一步。** 区分加载失败、真正为空、筛选无结果。分别提供重试、创建入口或清除筛选；保留输入和选择，不能将请求失败显示成零条记录。
- **修改原有规则。** 先定位实际生效的选择器，再调整对应组件或页面样式；不靠连续追加覆盖或 `!important` 叠加新主题。减少动效的全局保障规则可以保留。

原文提到的奶油背景、衬线字和编辑式布局并非禁用清单；这里是用户已经确认的设计选择。以任务和品牌为依据复用，不复制 Anthropic 配色或为规避“模板感”强行换肤。

正文与操作优先使用本地 Noto Sans SC Variable 无衬线字族。固定展示标题搭配站酷快乐体子集（`--font-display`），少量短句采用霞鹜文楷子集（`--font-note`），数字和快捷键使用 Fragment Mono（`--font-mono`）。首页第一行保留粗黑字，第二行使用活泼展示字；创作、项目、素材和登录的固定标题采用同一展示字。手写字只用于“今天”“一步步”等引导及故事入口，不进入输入框、用户标题、账单或长正文。详情见 [字体维护](TYPOGRAPHY.md)。官网标题桌面最大 106px，创作标题最大 62px，目录标题最大 52px，工作台方案标题 32px；控件与辅助文字遵循本文件顶部文字层级。大标题不影响表单字号。

## 页面结构

### 官网与登录

官网以“让想法，有画面。”、创作准备和自动循环宣传片组成首屏；最新布局、媒体加载及输入约定见本文件顶部。风格参考紧接首屏；下方通过四种用途与独立短片展示能做什么，示例不呈现虚构任务进度。

输入提供“参考视频 / 复刻网站 / 剧本 / 风格”，切换或换灵感不会覆盖已输入内容。准备创作将输入和起点留在本标签页会话，登录后追加到原草稿，不自动提交。文件进入工作室后添加。页脚帮助弹窗使用 ActionDialog。

用途示例：只保留四项，依次为「文字动画与视觉特效」「自动配音和字幕」「动态图表」「自动剪辑」。撤下风格复刻、音乐卡点与音频可视化的独立入口。每项配一支 5–6 秒原创 Remotion 短片，参考用户上传视频的黑白纸感、细颗粒、橙蓝点色、粗黑字与斜体衬线对比，分别展示粒子字形、旁白字幕、立体柱图与胶片精剪；不再采用重复的“准备 / 方案 / 视频”演示。说明文字分别讲清输出、处理方式与适用场景。页面仍保留黑白底色和蓝色选中态，桌面四行目录与影片分栏，窄屏目录收为双列。只加载当前可见示例，切换时卸载旧片；默认静音，可暂停、重播、拖动进度、试听和全屏。离屏、页面隐藏及参考影片弹窗打开时暂停；减少动效时先显示静帧。选择用途不编辑草稿或提交任务，“用这个功能开始”才向原输入追加要求，重复使用不重复填入，超出 6000 字时保留原文并提示精简。源工程在 `design-assets/capability-reels`，渲染文件由 Vite 打包；图表标注示例数据，旁白使用原创录音。

登录、邀请注册和重置密码采用简洁的居中单列表单，沿用首页的底色、字体及 YingYa 橙点字标。按用户 2026-10-06 的要求，登录页不放视频、品牌大标题或重复的首页介绍，只保留表单、注册切换、返回首页与联系管理员入口。少量代码风格装饰使用等宽字体的 `<YingYa>` 首尾标签和一条浅色缩进线，装饰不参与辅助技术阅读，不增加循环动画。密码可见性、校验、失败恢复与真实鉴权接口保持可用；桌面表单宽度 380px，窄屏保留左右留白。

### 创作与目录

正式入口 `/app#/`。左侧 188px 导航，右侧先提供参考视频、复刻网站、剧本和风格的准备引导，再填写创作目标与参考说明；音乐、参考图、视频、素材库与内置内容集中在「添加素材」菜单，不再单列一排重复入口；大纲直接填写在文本框，不设置独立上传项。移除「创作设置」，工具条以「约 30 秒」提供可调整的参考时长，旁白音色回到「添加素材」；文件角色、画幅、模型、生成参考图和生成图文方案处于同一容器。按用户 2026-10-06 的要求移除标题旁的 emoji 字符伙伴，以静态 `<Create>` 首尾标签作少量代码装饰，不参与辅助技术阅读；输入与操作用细线分隔。添加素材、参考时长、画幅与模型入口统一使用细边框、40px 高度与图标文字；菜单使用白底、浅阴影和蓝色选区，模型说明与思考深度分栏呈现，当前选择同时显示勾选。任务入口使用右上角悬浮铃铛，空任务面板以简短文字说明状态。下方用紧凑列表显示真实最近项目，等待审阅的项目优先。

`/app#/projects` 使用真实封面；没有封面时，使用项目标题排成黑白字形封面，不生成示例项目。搜索、筛选、排序、重命名与删除都连接已有接口；删除使用可取消、有失败重试的原生模态。

`/app#/assets` 保留文件夹、类型、搜索、来源、排序与批量整理。点击素材打开详情，支持预览、下载、移动、重命名与删除。图片生成、音色生成和克隆沿用已有接口与错误恢复。小屏导航在顶部，文件夹横向排列，目录减少列数。

### 制作工作台

顶部呈现项目名称、状态与分享下载；第二行是准备内容、审阅方案、制作视频、观看与修改。阶段由真实项目状态决定，点击切换相关视图，不改变任务进度。

桌面采用开放分栏与单条分隔线，左侧约 72% 为方案／视频／素材／制作详情，右侧约 28% 为创作助手，分栏可拖动和键盘调整。手机以对话、方案、视频、素材、详情五个等宽标签切换，保持所有能力可达。

方案只突出一张当前关键画面，下方选择段落、阅读讲法与表达、添加意见。视频目标和参考资料按需展开。底部唯一的“确认方案并制作”固定可见，绑定原检查点和修订；画面不完整或读取失败时不允许确认。

视频使用实际媒体播放控制：播放暂停、拖动进度、倍速、静音、全屏。可对时间点、画面选区或时间范围添加意见；草稿统一进入右侧助手并持久化，绑定原视频版本。输入框与当前任务状态保持易找，技术详情按需展开。

### 账户、管理与分享

账户、用量、账单、头像、版本、管理后台沿用同一颜色和控件体系。表格可局部横向滚动。分享页以真实视频为中心，失效和播放失败提供说明及重试；不替换用户头像和视频内容。

## 动效

首页宣传片、用途短片和参考影片遵循上方的可见性、暂停与减少动效规则，实际状态来自媒体本身。登录、创作和空状态不加载角色装饰影片；客户视频不跟随首页宣传片自动播放。

官网标题提供立体、粒子、打字入口，点击标题可重播。文字布局、辅助技术标签、草稿和输入位置保持稳定；开始输入、离屏、隐藏页面与减少动效时取消动作并恢复完整文字。灵感填入用短暂纸飞机反馈，目录和导航提供轻反馈；连续触发替换旧动画，不积累队列，不模拟生成进度。

## 验收

- 所有操作支持键盘和可见焦点，图标按钮有可理解的名称。弹窗关闭恢复焦点。
- 检查真实登录提交、注册/重置、创作草稿和提交、作品搜索与操作、素材分类/详情/批量整理，以及制作工作台原流程。
- 桌面检查 1280、1440、1536、1920 宽度；窄屏检查 390 与 320，包含长标题、空状态、失败与减少动效。图片、字体解码后实际查看截图。
- 运行 typecheck、web build、单元与相关浏览器测试。`tests/editorial-ui.mjs` 与 `tests/design-guidelines-ui.mjs` 使用隔离 API fixtures 检查布局、弹窗键盘操作、音色试听及失败恢复，不验证线上后端。
- 按部署规则单独发布与核验；合入分支或通过本地检查不代表已部署到线上。
