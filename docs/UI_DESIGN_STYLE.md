# 映芽产品 UI 设计基准

## 状态与适用范围

**2026-10-07，用户确认：产品设计定格为当前这一套。** 本文件统一描述现行规范，替代此前按改版日期追加的说明。官网、登录、创作、制作工作台、目录、账户、管理后台、弹窗与公开分享均适用。

冻结的是品牌、配色、字体分工、布局层级、控件语言与交互习惯。日常功能、缺陷修复、可访问性和性能改进继续沿用现有体系；新增页面从对应的现有页面与共享组件延伸。只有用户明确要求改变设计方向时才修改这套基准，普通修复无需另开一轮设计审批。

旧稿、归档素材、历史截图、版本记录、第三方模板和通用设计技能不能作为恢复旧主题或自行改版的理由。代码中仍有 `print`、`editorial`、`--purple-*` 等历史名称，它们是实现名称或兼容别名，不能据此恢复旧配色。若现行实现与本文冲突，先核对相关代码、实际页面和最近明确要求，定位偏差；不要按旧材料改写当前界面。

此约定只限制产品界面。客户视频、用户上传素材和官网示例影片有各自的内容与设计，不需要套用产品的黑白蓝配色。

## 品牌、颜色与字体

使用黑白字形画布、蓝色定位与选中态、开放布局和清楚的中文操作。官网、登录、工作室、管理与分享统一使用 **YingYa 粗体字标和橙色圆点**：复用 `web/src/marketing/BrandLogo.tsx` 与 `brandLogo.css`，浏览器图标为 `web/public/brand/yingya-monogram.svg`。不恢复山水、萌芽或幽灵主题；保留用户头像、作品和上传素材。

颜色值由 `web/src/styles.css` 维护，组件优先引用语义令牌：

| 角色 | Token | 当前值 |
| --- | --- | --- |
| 画布 | `--canvas` | `#f5f5f3` |
| 次级表面 | `--surface` | `#eef0ef` |
| 文字与主色 | `--text` / `--primary` | `#111310` |
| 次文字 | `--muted` | `#62676b` |
| 定位与选中 | `--signal-blue` | `#1875e5` |
| 状态强调 | `--signal-green` | `#5bca31` |
| 浅底状态文字 | `--signal-green-text` | `#267d16` |
| 分隔线 | `--line` | `#dedfe0` |
| 强分隔线 | `--line-strong` | `#adb2b1` |

品牌橙点由字标组件固定为 `#fa4c0c`，不扩展成全站操作色。状态除了颜色，还需文字或图标表达。

正文、用户内容与工作控件优先使用本地 Noto Sans SC Variable。固定展示标题使用站酷快乐体（`--font-display`），已有短引导使用霞鹜文楷（`--font-note`），数字、快捷键和少量代码标签使用 Fragment Mono（`--font-mono`）。字体子集不能用于任意用户输入；来源、覆盖范围和重建步骤见[字体维护](TYPOGRAPHY.md)。不因新增功能重新选字体。

### 字号、行高与字重

工作界面按内容角色选共享令牌，不按页面另造字阶。下表为映芽的使用规范；CSS 使用现有 rem 令牌，px 为根字号 16px 时的对照值。

| 用途 | 字号令牌 / 对照值 | 行高 | 字重与边界 |
| --- | --- | --- | --- |
| 时间、计数、补充说明 | `--text-caption` / 12px | `--leading-caption` / 1.6 | 400；辅助信息不能承载唯一的关键操作或错误恢复提示 |
| 按钮、菜单、筛选、字段标签 | `--text-control` / 14px | `--leading-ui` / 1.5 | 普通文案 400，操作与选项 500，选中或关键标签 600 |
| 连续阅读的正文 | `--text-body` / 15px | `--leading-body` / 1.75 | 400；长说明、方案和消息按阅读密度选择正文样式 |
| 面板与弹窗标题 | `--text-section` / 16px | `--leading-heading` / 1.3 | 600；含关闭控件的标题行可沿用 1.5，垂直居中 |
| 工作区分区标题 | `--text-subheading` / 20px | `--leading-heading` / 1.3 | 600；比面板标题高一级时使用 |
| 普通内容页标题 | `--text-title` / 24px | `--leading-heading` / 1.3 | 600；不覆盖已定格的展示标题与方案标题 |
| 普通文字输入、搜索 | `--text-field` / 桌面 14px、800px 以下 16px | `--leading-ui` / 1.5 | 400；登录沿用 16px，手机输入不因紧凑布局缩小字号 |

- 400 / 500 / 600 分别对应 `--weight-regular` / `--weight-medium` / `--weight-emphasis`。先用分组、位置和字号表达层级，再选择字重；不要让整块正文、所有按钮和元信息都加粗。普通工作标题显式设字重，避免继承浏览器默认的 700。
- 同一工具条的时长、画幅、模型、排序等文字角色相同，字号、行高和基线应一致。创作与工作台输入工具条采用下文明确的紧凑例外；其他新增普通控件不再引入 13px、550、650 等独立档位；已有差异按实际可读性和同组一致性局部收敛，不做全站数值替换。
- 除创作与工作台输入工具条的紧凑例外，12px 用于次要说明。手机上的操作标签优先保持 14px，不能靠缩到 11–12px 解决拥挤；先换行、分组或渐进披露。文字输入、搜索和时长数字输入在窄屏使用至少 16px，验证聚焦、键盘弹出及长内容。
- 创作长输入沿用现有组件的宽松行高，默认创作框为 16px / 1.75。普通中文正文和控件保持正常字距，不用负字距塞入更多文字；数字对齐优先使用现有等宽字体或 `tabular-nums`。
- 展示字的视觉粗细不等于 UI 字重：站酷快乐体和文楷子集按已有 400 使用，不人工加粗。字标、首页标题、作品字形封面保留自身字重与响应式规则。首页桌面标题为 `clamp(56px, 4.6vw, 68px)`；其他断点以 `marketing/homeStage.css` 为准。现有方案标题的 28px / 手机 25px 也不因补齐字阶而批量改写。

### 间距、密度与对齐

新增或修正工作界面时，以 **4px 为间距步进**，先确定元素关系，再取值；组件内部间距、组件间距和容器内边距分开管理。

| 关系 | 默认取值 | 使用方式 |
| --- | --- | --- |
| 紧密附属信息 | 4px | 标题与紧随的状态、选项内部主副文字 |
| 图标与文字、同组小操作 | 8px | 图标和文字垂直对齐，不靠空格撑开 |
| 同组控件、标签到输入框 | 8px / 12px | 同组同值；有清晰标签的表单优先标签下 8px |
| 表单字段、列表小分组 | 16px / 20px | 组内关系明显近于下一组，不逐字段随机取值 |
| 独立信息组、面板内容内边距 | 24px | 窄屏通常 16px / 20px；先复用对应组件的现有布局 |
| 页面主要分区 | 32px / 40px | 分隔较大的内容块，官网展示区域继续沿用现有留白 |
| 文字筛选导航 | `--tab-gap` | 桌面 24px、窄屏 20px；与紧凑分段控件区分 |

以上是维护默认值，不要求所有长度都成为 4 的倍数：1px 分隔线、2px 选中线、现有 6px 圆角、图标光学校正、按边框计算的内边距与已定格展示布局各有用途。已有 18px 等局部值不单凭数值被判为缺陷；只有相同语义不一致、对齐错误或内容拥挤时才调整。当前没有统一的 `--space-*` 令牌；复用现有组件与变量，确有多处共用的新间距再集中定义，避免只写文档却声称代码已统一。

标题、说明、字段和列表正文共用清楚的起始边线。同一行的控件高度与文字基线协调；普通选择控件与常规操作统一至少 44px，手机上的关键图标触达区至少 44px。图标画面通常为 16–20px，触达区独立于图标大小。窄屏空间不足时先让说明移到标题下、工具条换行，保留完整动作名，不挤压标题成孤立的单字，也不让按钮互相覆盖。

### 飞书 / Lark 参考的采用范围

参考核对日期：2026-10-07。采用飞书公开资料中关于层级、成组间距、统一控件和清楚状态的做法，具体落地值仍以上述映芽规范为准：

- [飞书开放平台：锚点](https://open.feishu.cn/document/design-specification/component---navigation/anchor?lang=zh-CN)给出锚点标题 14px、与其他元素至少 24px、调整按 4 的倍数取值的建议。原文适用于页内锚点；映芽借鉴其字阶和间距节奏，不将锚点宽度、位置或最小边距套用到所有组件。
- [飞书开放平台：图标按钮](https://open.feishu.cn/document/design-specification/component---data-entry/button/button_icon?lang=zh-CN)区分不同密度的操作，同组间距采用 8px / 12px，并强调图标含义、提示和展开后的状态。映芽保留自身控件尺寸和手机触达要求，不照搬其紧凑桌面按钮高度；纯图标操作需可访问名称和可发现的提示。
- [飞书：页面布局与样式设计](https://www.feishu.cn/content/916719437860)区分组件间距离与边框到内容的距离，并提供换行、对齐及伸缩规则。映芽采用这套区分方法，保留现有响应式分栏，不改造成新的栅格或品牌系统。

这些资料不构成飞书 / Lark 全产品、所有版本的完整字体规范。上面的字体家族、15px 正文、400 / 500 / 600 字重与行高是映芽对当前体系的整理与补充，不能标注成“飞书官方数值”。外部参考更新不自动改变已定格的设计。

## 共享控件与文案

- 按钮采用共享 `--radius-button`（10px）、`--button-height`（44px）和 `--button-*` 表面、边框与阴影令牌。主要操作黑底白字、轻微内高光；次操作白底细边框；辅助操作透明底，悬停显底色。按钮和菜单文字为 14px / 500，焦点用蓝色轮廓，按下提供明度反馈，禁用保留可读性且无浮起阴影。删除等危险操作保留红色语义。
- 普通下拉复用 `SelectControl`：10px 圆角、至少 44px 触达高度，白底菜单、蓝色选中、独立箭头与勾选。模型等复合菜单沿用同一体系。文字导航保留下划线与直角，播放、头像与内容卡片保留各自的形状；工作页输入工具沿用下述局部圆角层级。
- 文字筛选间隔使用 `--tab-gap`（桌面 24px、窄屏 20px），分段控件保持现有紧凑分组。不要为同类控件再造字号、间距和阴影。
- 弹窗复用 `ActionDialog` / `EditorDialog`，保证焦点限制、Escape、关闭后焦点恢复。可取消浮层支持外部点击或焦点离开关闭；内层菜单先处理自己的 Escape。破坏性操作保留明确确认与失败恢复。
- 空白、加载、真正为空、筛选无结果和请求失败分别表达。空状态说明下一步，失败保留输入与选择并提供重试；不把错误显示成零条数据，不模拟进度。
- 素材库上传逐文件显示等待、传输、服务器保存、成功与失败，成功项即时可用，失败项可重试。创作输入框内的附件用紧凑缩略图或文件卡片呈现，支持点击预览和角标移除；拖入、粘贴直接作为参考，不显示用途选择或“已添加附件”的成功提示。附件在发送时上传，传输与失败状态附在对应缩略图上，失败后保留草稿供重试。
- 使用已有 Phosphor 功能图标；界面不增加 emoji、字符伙伴、角色影片、贴纸或重复功能卡片。装饰不替代操作提示，不进入辅助技术阅读。
- 操作名贯穿按钮、过程和结果，例如“保存名称”对应“名称已保存”。保持中文产品语气；实现细节与技术输出按需展开，不能挤掉输入、当前任务或恢复操作。

## 页面基准

### 官网

首屏左侧是“让想法，有画面。”和紧凑准备表单，右侧是完整 16:9 宣传片；最大画布 1440px，900px 以下依次为标题、准备、影片。沿用现有标题字形互动、影片薄边与蓝色偏移线框，不增加第二组标题、重复宣传片入口或播放说明。

准备表单保留“参考视频 / 复刻网站 / 剧本 / 风格”四个起点。切换不覆盖输入；“准备创作”将选择和文本保存在本标签页会话，登录后追加到已有草稿，不自动提交任务。下方没有重复流程提示或“换个灵感”按钮；文件在工作室添加。

风格参考保留当前九支影片、真实封面、中英文标题与时长，沿用错落双列和响应式尾排。悬停只加载当前一支静音预览，离开卸载；点击打开带原音轨的模态，支持前后切换、关闭及焦点恢复。“用这个风格准备创作”追加真实链接并聚焦输入，不提交任务。

用途示例依次为“文字动画与视觉特效”“自动配音和字幕”“动态图表”“自动剪辑”，分别配现有短片；桌面目录与影片分栏，窄屏目录为双列。选择用途只切换展示，“用这个功能开始”才追加要求，不覆盖原文、不重复填入；超过 6000 字时保留原文并提示精简。示例图表明确是示例数据，不能呈现虚构的用户任务进度。

### 登录与账号入口

登录、邀请注册、重置密码使用居中单列表单，桌面宽度 380px，窄屏保留留白。保留返回首页、表单切换、密码可见性、校验与恢复；不放品牌大标题、介绍视频或重复首页内容。现有 `<YingYa>` 标签与浅缩进线为静态装饰。密码和账号规则统一见[用户沙箱](USER_SANDBOX.md)，不在设计规范维护另一份账号策略。

导航账号入口只显示已有头像，触达区 44px；邮箱和身份在菜单顶部。一级菜单为“使用情况 / 设置 / 帮助 / 退出登录”，分别归入用量与账单、头像与管理员账号管理、版本记录与联系管理员。二级菜单保留悬停展开、边缘翻转、窄屏内展开，以及点击、触屏和键盘进入/返回；悬停不移动键盘焦点。Escape 先回上一级，再关闭并恢复头像焦点。

登录相关页面与账号菜单的“联系管理员”复用 `ContactAdminDialog`，站内展示现有联系邮箱并提供复制，复制失败可手动选择；不直接唤起邮件客户端，也不提供发信表单。邮箱值由该组件维护。关闭方式与焦点恢复沿用共享模态。

任务中心是右上角固定 44px 铃铛，与头像错开；未读圆点配屏幕阅读器提示，悬停名称为“任务中心”。窄屏不遮挡标题或关键操作，空任务面板只显示简短状态。

### 创作与目录

`/app#/` 使用左侧 188px 导航和右侧创作区域，窄屏沿用顶部导航。先选准备起点，再描述目标；“添加素材”集中音乐、参考图、视频、素材库、内置内容及旁白音色，大纲直接填文本，不恢复独立“创作设置”。输入框底部将添加素材、时长、画幅、模型和提交箭头始终放在一行，统一“开始创作”入口，不再分别展示生成参考图和生成图文方案。提交后按现有流程准备内容方案和关键画面，确认后制作；已有草稿和选中的参考图保留。时长默认约 30 秒。创作工具条为紧凑例外：桌面字号 13px、控件高 36px；600px 以下字号 12px、控件高 44px，添加素材只显示加号，时长和画幅保留数值，长模型名省略，380px 以下收起思考深度简写。所有触发器有完整可访问名称与提示，菜单仍为 14px，手机数字输入仍为 16px；字幕、语言、声音和最终时长按用户要求与真实素材进入方案，不由音色偏好强制添加旁白。

创作区使用现有 `<Create>` 标签、细线与统一工具控件；模型说明和思考深度分栏，当前选项有勾选；触发器提示及可访问名称明确思考深度，展开后显示“思考深度”分组，不把推理深度误作视频质量。视频帧率随制作源确定，清晰度在导出时选择，创作入口不暴露编码与渲染技术参数。下方列真实最近项目，等待审阅的项目优先。320px 创作起点采用两列，避免不可操作的挤压。

`/app#/projects` 与 `/app#/assets` 使用紧凑开放目录。页首只显示“项目 / 素材”现有展示字，标题与新建或上传主操作同排；主操作与任务中心均为 44px 高，桌面顶部对齐；不加介绍文案、装饰代码标签或统计卡片。项目页下一行集中状态筛选及分类数量、搜索、排序和网格 / 列表切换，显示偏好按账号保存，筛选结果数量向屏幕阅读器播报。“可导出”与“已导出”分别筛选，卡片使用同名状态，不显示源文件更新描述。打开项目直接进入独立加载态，失败可重试或返回项目，不能短暂显示创作首页。桌面网格按宽度显示 3–5 列，手机收为小封面横排；列表对齐名称、状态、画幅与更新时间，窄屏将元信息放在标题下。素材页一级标签与标题同排，空间不足时标签另起一行，保留完整上传操作名。作品使用真实封面，缺图时用标题字形，不生成示例项目。保留搜索、筛选、排序、重命名、详情与删除恢复；素材另有文件夹、类型、来源、批量整理和下载。素材拖入文件夹或“未整理”时有蓝色、虚线和文字反馈，失败项保留选中；键盘与触屏通过批量整理获得同等能力。

素材区支持拖入本地文件或点击上传，保存到提交时选中的文件夹；“全部素材”和“未整理”中的上传归入未整理。拖入时明确显示目标位置，区分本地上传和已有素材整理。

素材区按任务分为“素材库 / 生成素材 / 任务记录”。素材库只管理文件，保留图片、视频、音频、文档、其他分类、搜索、文件夹、显示方式与批量整理；类型数量跟随当前文件夹，工具行显示当前位置与结果数。来源、显示方式与排序使用共享下拉，默认中图并尊重已有显示偏好，卡片的来源与文件夹分行左对齐，上传是主操作。中／小图和文件列表的文件名字号为 13px，大图为 14px，均使用完整 UI 字体；桌面列表行高约 52px，以留白与悬停底色区分条目。类型仅显示 PNG、PDF 等格式；列表名称、类型、来源、文件夹和添加时间列头可切换升降序，排序下拉提供同等能力。进入批量整理后，鼠标或触控笔可在素材内容区空白处拖动框选，包括列表两侧与末尾下方的留白，光标显示十字；空白处单击或双击保留已选项，取消选择通过点选文件或取消全选完成。Shift／Ctrl／Command 拖动追加选择，靠近边缘自动滚动，Escape 取消本次框选；文件本身仍可拖入文件夹，键盘和触屏保留点选、全选与移动。手机保留双列中 / 小图和可切换的单列大图 / 文件列表；极窄屏批量整理使用有完整可访问名称的图标按钮。生成素材内用“图片 / 音色”子标签，不把音色当作音频文件分类；后续生成能力沿用同层级，不预设不可用入口。图片页地址为 `/app#/assets/generate/image`，音色页为 `/app#/assets/generate/voice`；旧 `/assets/image`、`/assets/voice` 地址兼容。图片创建采用完整页面，宽屏表单与结果分栏，窄屏纵向排列；文字和参考文件草稿按当前账号保存，生成后可下载、查看素材库或复用参数。

生成素材默认以类型与编号命名，上传原名和用户改名优先；提示词不充当列表、附件、详情标题或下载文件名。已有文件按原编号展示，不改动物理路径与项目引用。详情保持短标题和可达关闭按钮，先显示预览及文件信息，再按需展开、复制完整提示词；长文字不能挤走媒体。

“任务记录”使用独立页面 `/app#/assets/tasks`，统一列出上传、图片和音色，可按类型与状态筛选，一级入口显示进行中数量。上传逐文件显示等待、实际传输、服务器保存及结果，失败可单独重试；上传期间保持页面打开，站内切换不打断队列，记录保留在本次会话。图片和音色生成由服务端保存并在后台继续，刷新或离开页面后仍可查看；详情保留输入、参考、结果或失败原因，可编辑后重试。完成图片进入素材库，音色进入音色库；读取失败保留已有记录，不显示为零条记录。已完成与失败记录可单条删除，“清理已完成”只处理当前类型分类中的完成记录，不删除素材或音色；进行中的任务不可删除，失败项保留重试。清理结果持久保存，刷新与轮询不恢复已删除记录；上传历史随当前会话保存。

音色页集中管理音色库和创建流程。列表保留搜索、来源筛选、自定义文案试听与下载、设为新项目默认、名称与说明编辑，以及有确认的删除；内置音色不可编辑或删除。描述生成和授权克隆共用页面创建区，克隆支持录音、上传、原音试听和参考文字，校验 1–30 秒及 10 MB 上限。表单与参考音频草稿在当前账号的浏览器中保存，授权复选框不自动恢复；克隆任务重试可恢复参考音频，但必须重新确认授权。项目内弹窗只做选择和试听，创建与管理统一进入音色页；删除的项目引用规则见[用户沙箱](USER_SANDBOX.md)。

### 制作工作台

顶部只保留项目、真实状态与分享下载，不显示编号流程或阶段步骤条。右侧仅保留“预览、项目内容”，切换视图不改变制作状态。

桌面为左侧对话、右侧内容的开放分栏；对话默认约 440px，支持拖动、方向键及 Home/End 调整与宽度保存；对话最窄 280px，最宽可拖至右侧内容保留 400px，双击分隔线恢复默认宽度，输入框固定在底部。手机以对话、预览、项目内容切换，全部能力可达。失败提示将原因按需展开，操作放在正文下方，长错误与链接不能挤压正文。

工作页沿用用户选定的柔和圆角：弹窗 24px，菜单和提示面板 20px，消息气泡与媒体 16px，常规控件 12px、小状态标签 8px；对话输入容器使用与首页一致的 12px 圆角，工具按钮使用共享 10px 圆角；圆形头像与直线分隔保留。此圆角层级仅应用于工作页及其浮层。添加素材、模型、停止和发送始终放在同一行；桌面控件高 36px、模型文字 13px，600px 以下高 44px、文字 12px，长模型名省略，展开菜单保留完整名称和 14px 字号。参数与添加素材使用透明底、悬停显底色和蓝色展开态；输入文字与草稿机制不缩减。对话区不再设置重复的标题与状态栏，消息直接从项目顶栏下方开始；项目状态保留在全局顶栏，标题修改失败时按需显示错误提示，不保留常驻栏。

项目内容汇总当前项目实际生成的文件、成片和已加入的素材，默认按“成片与版本、方案与文稿、素材、制作文件”分组；成片依据已登记版本识别并标出当前版本，制作文件默认收起，已登记的参考资料不因文件格式而收进工程文件。标题沿用展示字“项目”与 UI 字“内容”，组序号使用现有等宽字体；素材与文稿在内容栏宽度足够时使用双列紧凑目录，窄栏回落单列。横线仅分隔相邻大类，文件条目使用留白与悬停底色，不逐行划线。每行优先显示名称、格式与大小，可切换完整文件列表查看路径，支持最近更新或名称排序；视图、排序与各项目分组折叠状态按账号保存。视频、图片、音频、文档及其他分类和名称／路径搜索覆盖所有分组，包括收起的制作文件，筛选结果统一平铺，清除后恢复分组状态。保留明确的单文件预览入口，预览中可下载或加入对话，关闭后保留分类、搜索与草稿；全局素材库从“添加素材”进入。制作中自动刷新，新文件无需等产物登记即可出现。视图切换与分组展开沿用轻入场和悬停反馈，并遵循减少动态效果设置。

不再设置独立方案页。遇到已有制作检查点时，从对话打开确认弹窗，展示关键画面并保留补充意见。“确认方案并制作”保持可见，绑定真实检查点与修订，画面不完整或读取失败时不能确认。批准后的制作、内部审阅与直接交付遵循[视频制作流程](VIDEO_PRODUCTION_WORKFLOW.md)，不新增设计审批或草稿审批。

工作台统一预览当前选中版本的成片，不提供“实时画面”切换或完整 Remotion Studio。制作中显示进展；修改时保留上一版视频可看，新版就绪后按版本选择规则展示。尚无视频时显示制作状态与现有项目内容入口，不展示空播放器，也不要求用户在对话中修复工程预览。Remotion Player 继续用于底层制作与检查。镜头列表只提供段落定位，不再设置仅追加提示词的文字、动效、声音、节奏和意见快捷按钮；修改统一从对话或时间点、选区、范围反馈进入。源文件更新只在顶部项目状态提示，不在预览标签栏重复显示。

成片控制使用真实播放、进度、倍速、静音和全屏；时间点、画面选区和范围意见绑定原视频版本，草稿持久保存。分享、下载和其他规格导出集中到顶部“分享与下载”弹窗，预览底部不重复设置入口；规则见[视频分享](VIDEO_SHARING.md)。输入与当前任务始终易找，命令输出、调试信息和次要操作逐步展开。

### 账户、管理与公开分享

账户、用量、账单、头像、版本和管理后台复用同一颜色、字体和控件。表格可局部横向滚动，窄屏不隐藏关键管理操作。公开分享以真实视频为中心，失效与播放失败有说明和恢复操作；不改动用户内容。账号权限、额度、账单及分享生命周期由对应业务文档维护。

## 媒体与动效

沿用现有交互反馈与少量字形效果，不新增动画库或装饰循环。标题的立体、粒子、打字效果可以重播；开始输入、离屏、隐藏页面或减少动效时停止并恢复完整文字。示例追加可保留现有纸飞机反馈；连续操作替换旧动画，不累积队列，不模拟生成进度。

官网主片、参考和用途短片遵守可见性、用户暂停意图及播放互斥。隐藏页面或离屏暂停；参考预览/模态打开时暂停主片，结束后恢复原有意图。减少动效时先展示静帧，悬停不触发视频，手动播放仍可用。

播放器保留暂停、进度、重播、声音、全屏与失败重试；浏览器阻止有声播放时给出主动开启声音的操作。桌面播放条在鼠标离开后隐藏，悬停或键盘操作时可达；触屏保持可操作。客户成片不随官网宣传片自动播放。

当前官网使用 H.264/AAC、faststart 和单版本资源。规格与来源以 `web/src/assets/showcase/encoding.json`、`design-assets/capability-reels/renders.json` 为准，制作入口见[项目结构](PROJECT_STRUCTURE.md#preventing-unused-product-code)。短片内部的纸感、颗粒或橙蓝表现不扩展为产品 UI 主题。

## 工作方法与参考边界

1. 明确本次用户任务、受影响页面、复用组件与验证范围；小修用简短说明，不重做风格提案。
2. 对照本基准和当前实现，保留有效布局、数据、草稿与操作流程，再完成局部改动。
3. 查看截图并实际操作受影响状态；发现偏差时修正原规则，报告实测范围及限制。

方法来源仍保留用户指定的 Anthropic [frontend-design/SKILL.md](https://github.com/anthropics/claude-code/blob/dbdd79cebfae5891f5b0fab6f7773ea520d289a7/plugins/frontend-design/skills/frontend-design/SKILL.md)，固定于 `dbdd79cebfae5891f5b0fab6f7773ea520d289a7`。适用部分已归纳为任务优先、清楚排版、克制装饰、可执行文案和截图复查。原文也要求尊重已明确的方向；它的风格探索流程不在每次维护时重新启动。日常按本文执行，核查方法来源时再读固定原文，不自动追随上游新版或借参考另起主题。

## 验收范围

按改动选择相关行；影响共享布局、令牌或控件时扩展至所有使用它的页面。风格定格不冻结功能迭代，文档整理也不要求重新设计整站。
