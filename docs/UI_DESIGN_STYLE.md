# 映芽产品 UI 设计规范

## 当前方向：奶油纸与靛蓝的编辑式界面（2026-09-30）

本轮经用户确认的首页、登录、创作、作品和素材预览已接回正式 React 应用。沿用既有印刷插画与视频，使用留白、衬线标题、细线和开放目录形成层级。上一轮规范保存在 [归档](archive/pre-editorial-home/UI_DESIGN_STYLE.20260929.md)。旧山水和小怪兽主题不再作为当前 UI 选项。

- 一屏一个重点，不堆叠贴纸、口号、装饰边框或功能卡片。
- 奶油纸、靛蓝是主体，橙色保留在角色和必要操作中。状态同时提供文字或图标，不只靠颜色。
- 保留原小鬼轮廓的深蓝 SVG：`web/public/brand/yingya-ghost-navy.svg`。用户头像、作品和上传素材保持原样。
- 插画不承担控件和文字；使用已有 Phosphor 图标，不使用 emoji 作为界面图标。
- 设计预览的示例数据不写入真实账户。真实登录、创作、作品和素材仍调用原接口。
- 产品定位遵循 [产品定位](PRODUCT_POSITIONING.md)：把内容、网页和素材制作成可讲解、可分享的视频。

## 令牌与实现入口

共享工具布局在 `web/src/print-studio.css`；本轮页面在 `web/src/editorial-studio.css` 中用 `.editorial-shell`、`.editorial-assets` 限定，避免覆盖制作工作台。官网使用 `marketing/printHome.css` 和 `marketing/splitHome.css`；登录使用 `components/editorial-login.css`。

正文与工作控件继续使用系统无衬线字体，中文回退 Noto Sans SC。新的展示标题使用本地 Noto Serif SC Variable 900，官网使用本地思源宋体 Heavy 子集和 Bodoni Moda Italic。不复制外部品牌专有字体。创作标题桌面最大 70px，作品标题 52px，素材标题 46px；工作控件约 14–16px，辅助文字通常 12px。展示字重不进入正文和表单。

中文界面提示保持简短，不添加句末句号；用户原始文本、方案和视频内容保留标点。

## 页面结构

### 官网

左文右片的分栏首屏：标题、介绍与开始创作在左，六幕影片在右。下方保留灵感介绍和三幅场景。导航只保留 GitHub（带 Logo）与进入创作。所有创作入口使用 `/app`。

影片保留原生 1344×768、7:4 比例，最大展示宽度 1040px，不拉伸，不将放大声称为 4K。沿用蓝发、橙色贝雷帽、相机角色与现有影片；媒体位于 `web/src/assets/home-cinema`。

### 登录与注册

`/app` 未登录时呈现左表单、右角色的奶油纸布局。角色为橙发、戴墨镜、挥手的小姑娘，素材在 `web/src/assets/editorial/login-girl.*`。登录提交真实鉴权接口，成功后进入工作台，不显示预览中的“账号信息未提交”。邀请注册、密码重置、错误提示、密码可见性和忙碌状态保留。

### 创作

正式入口保持 `/app#/`。桌面左侧为衬线标题和精简输入区，右侧为深蓝双丸子头、橙色开衫、抱着速写本的小姑娘。素材在 `web/src/assets/editorial/create-girl.*`。不保留 Action! 大字或“最近创作”；历史作品统一到作品选项卡查看。

输入区保留附件、素材库、画幅、模型和生成方案。草稿、附件角色、设置、幂等创建及已有任务恢复逻辑不因换版丢失。

### 作品与素材

- `/app#/projects`：开放的三列封面目录，标题、真实状态、画幅和日期在封面下方。筛选、搜索、更新或名称排序、新建、打开、重命名和删除保留。打开作品进入真实制作工作台。
- `/app#/assets`：桌面保留独立文件夹侧栏，内容区包含标题与上传/创建操作、类型、搜索、来源和排序。图片、视频、音频、音色、文档继续使用真实素材库。
- 素材详情只在点击后打开，采用原生模态抽屉，支持 Escape、焦点恢复、预览放大、下载、重命名、移动和删除。批量整理、上传、生成图片和音色创建继续使用原接口。
- 窄屏保持顶栏入口可用，文件夹横向排列，作品与素材网格依宽度减少列数。不得横向撑出页面。

### 制作工作台、账户和分享

制作时左侧对话、右侧方案或视频，输入与当前任务状态容易找到。技术日志按需展开。分栏调整支持键盘和持久化；方案确认绑定检查点与修订，反馈绑定视频版本、时间点或选区。换肤不能重启任务、自动播放用户作品或丢失草稿。

用量、账单、后台使用纸色和可读的表格层级。分享页以真实视频为中心，失效状态可读。不能为视觉统一替换用户上传头像。

## 动效

首页、登录和创作装饰影片默认静音、持续循环，不显示播放/暂停按钮。仅在可见且页面激活时加载和播放；离屏或隐藏页面暂停，恢复可见后继续。`prefers-reduced-motion` 下不请求装饰视频，保留静帧。媒体失败或自动播放受限时不阻塞表单与导航。

用户作品不跟随装饰影片自动播放；作品播放器保留原操作。应用状态素材继续使用共享 MaterialFilm。普通交互沿用共享动效时长，输入和状态即时响应。

## 验收

- 所有操作支持键盘和可见焦点，图标按钮有可理解的名称。弹窗关闭恢复焦点。
- 检查真实登录提交、注册/重置、创作草稿和提交、作品搜索与操作、素材分类/详情/批量整理，以及制作工作台原流程。
- 桌面检查 1280、1440、1536、1920 宽度；窄屏检查 390 与 320，包含长标题、空状态、失败与减少动效。图片、字体解码后实际查看截图。
- 运行 typecheck、web build、单元与相关浏览器测试。`tests/editorial-ui.mjs` 使用隔离 API fixtures 检查新布局及操作，不验证线上后端。
- 按部署规则单独发布与核验；本轮合入 master 不代表已部署到线上。
