# 新版知识讲解视频：实施与验收记录

日期：2026-09-20。本轮已实现并发布新版产品，工程检查与真实内容验收分别记账。**三条视频可观看，但完整发布验收尚未达成：产品内两轮修改、严格字幕人工核对、三人理解测试和真实手机软键盘测试仍未验收。** 不以界面模拟测试或本地续作替代真实 Agent 制作链路。

## 已交付实现

- 首页“把内容讲清楚，做成可以分享的视频”、三条可修改的起始建议与三个真实视频案例；统一“新建视频、我的作品、素材工坊”。默认中文知识讲解、1–3 分钟、横屏 1080p/30fps，可对话修改。
- 对话／方案／视频工作区；桌面分隔条支持拖动、键盘、双击复位和本地保存，移动端标签切换；输入框持续可用；移除用户编辑器、时间线与隐藏高级入口。历史工程仍可读、播放、导出。
- 视频生成模型入口、供应商配置、能力探测路由与 MCP 调用工具退出当前链路；新建 ai-video 请求明确拒绝。图片、已有视频、配音、字幕与 HyperFrames 渲染保留。
- 结构化方案、真实制作源关键画面、修订绑定／并发去重确认、实际源文件归档；过期、生成中或不完整方案不能误确认。旧方案文档保留兼容展示。
- 时间点／截图／时间范围反馈、原视频版本绑定；文字、截图与未完成框选对话框均在同一浏览器恢复。历史反馈按稳定段落身份映射当前版本，不猜测旧时间码；队列等待期间出现新版本仍按来源映射。
- 逐项反馈结果必须关联新视频、版本质量报告、修改证据与范围检查；无法定位或完成时保留原因。源路径兼容 HTML 文件和目录；Markdown 审阅报告不会被错误当作 JSON 检查结果。
- 系统方案确认在聊天中只显示简短确认，内部修订字段保存在原始记录，不挤占对话。长引用自动换行。制作失败保留最近结果、输入与原因；服务额度耗尽和容量不足有明确提示。失败且已暂停的任务在启动审计时不会被覆盖原因或自动恢复。
- 六类内部表达组件：概念拆解、步骤流程、并排比较、数据变化、因果关系、素材聚焦标注。完成实际导出与可重复定位检查，不作为用户模板选择任务。
- 现有不可变分享副本、明确版本、下载、匿名播放保留。示例视频采用内容哈希文件名，旧资源与发布快照保留。
