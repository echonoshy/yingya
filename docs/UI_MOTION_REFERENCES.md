## 本次落地

- 白色画布、冷灰导航、墨色主按钮、冰蓝选中表面，统一使用语义 token。
- 项目筛选、工作台标签与手机视图标签共享一个连续移动标记；窗口、字体和计数变化时重新测量。
- 作品逐个短距离出现；封面悬停缩放至 1.025，打开提示淡入，键盘聚焦同样显示提示。
- 模态框打开时淡入并移动 8 px；关闭按钮与 Escape 快速收起，恢复触发点焦点。业务完成后的直接关闭保持即时。
- 任务面板和模型菜单使用可中断的开合；关闭中的内容不可操作。
- 视频首次载入与切换版本后淡入，不通过额外重挂载、自动播放或改变播放位置制造动效。
- 160 / 240 / 360 ms 分别对应快速反馈、标准切换和面板进入；作品依次延迟 28 ms，累计不超过 140 ms。
- 系统减少动态效果时直接到达最终状态，偏好在动画中途改变也生效。

实现依据与质量检查以 [UI_DESIGN_STYLE.md](UI_DESIGN_STYLE.md) 为准。交互回归覆盖连续切换、响应式对齐、动态关闭动画、焦点恢复与原有创作流程。


## 整体视觉复审：明亮的影像工作室

当前页面复审发现：首页标题为 38 px / 700 字重，模型按钮为 11 px 等宽字体；工作区对话为 14 px，大量状态与检查器说明为 11 px。偏蓝的边框与背景、密集的小字共同强化了开发工具的感觉。

保留导航与页面结构，调整的是以下视觉层级：

| 检查步骤 | 发现与处理 | 验证 |
| --- | --- | --- |
| 1. 首页与创建入口 | 标题改为 32–40 px / 600，控件使用 13 px 界面字体，辅助信息提升至 12 px；减少建议入口与封面的重复边框 | 桌面、390 px、320 px 实际页面检查通过 |
| 2. 创作对话与作品预览 | 阅读正文提升到 15 px / 1.8 行高，输入 16 px；检查器层次、画幅和版本信息使用统一字体，代码与时间码保留等宽 | 对话、预览、弹窗、动态标签与键盘回归通过 |
| 3. 素材工坊 | 日期、分类计数与格式标记使用一致字号；统一连接状态和选择表面的颜色 | 桌面与 320 px 检查通过 |

配色由偏蓝灰调整为更中性的雾灰：白色 `#ffffff`、应用背景 `#f3f4f6`、石墨 `#24262b`、系统蓝 `#006bd6`，选中表面为 `#edf3ff`。警告与错误保持语义色。字体优先系统无衬线，并保留本地 Noto Sans SC 中文回退；不引入新的在线字体请求。

保留上一轮的 160 / 240 / 360 ms 动效体系，将剩余控件反馈纳入相同时长；模型与音色选择的文本箭头改为 Phosphor 图标，并在展开时转向。

依据 [Apple 字体指南](https://developer.apple.com/design/human-interface-guidelines/typography) 中以字号、字重、颜色建立层级并控制字体数量的原则，以及 [Apple 色彩指南](https://developer.apple.com/design/human-interface-guidelines/color) 中保持色彩语义一致的原则。这里的 Web 字号和配色为映芽自身选择，并非照搬原生平台尺寸。
