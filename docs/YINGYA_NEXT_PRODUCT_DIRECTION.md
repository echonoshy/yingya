# 映芽新版：可分享的知识讲解视频

2026-09-20 实施基线

本轮用户已授权实施完整新版。本稿合并此前讨论与用户确认的设计，取代旧讨论中的“仅规划”“可选试做”、编辑器入口、模板目录和制作模式选择；产品不再暴露这些流程。实际验收记录见 `YINGYA_KNOWLEDGE_ACCEPTANCE.md`，不能从本节推断视频验收已通过。

### 固定体验

提供内容 → 查看大纲与实际关键画面 → 确认制作 → 观看视频 → 截图、时间点或时间范围反馈 → 查看修改版 → 分享/下载。默认建议中文、1–3 分钟、16:9、1080p/30fps，可通过对话改变。重点是知识、数据和素材辅助讲解；动态演示录制、完整 PPT 导入导出、通用混剪不属于首版。

导航统一为新建视频、我的作品、素材工坊。首页文案“把内容讲清楚，做成可以分享的视频。”；三个起始建议只填入可修改示例；主动作“生成方案”。沿用浅色、Phosphor 与语义令牌。

桌面 ≥1024px：对话默认约三分之一，320–560px 可拖动/键盘调整，预览至少480px；双击恢复，同浏览器保存。不足1024px以对话/方案/视频切换，制作详情是次级入口。无时间线、图层、参数面板或隐藏高级编辑器。输入和任务状态始终可找，运行中意见默认排队；立即执行明确提示中断当前任务。

方案含受众、核心问题、结论、稳定段落ID、“讲什么/怎么表现”、预计时长/画幅/旁白/素材缺口。代表画面数量为 min(3, 段落数)，从实际制作源渲染；其余段落不放假画面。段落/画面意见引用对象并聚焦输入。方案修订使旧确认失效，更新或关键画面未就绪不能确认。确认后直接制作全片，内部样片检查不增加审批。

视频反馈暂停并绑定原版本、精确时间与归一化选区；每批最多8条。范围反馈必须有确定的起止，模糊口语保留原文。刷新保留文字/截图，不承诺跨设备。历史反馈通过稳定段落身份定位，无法对应则澄清。每条意见显示排队、处理、未完成或已修改；已修改需新视频、质量报告、修改证据及服务端范围核查，不能只凭模型口头声明。普通局部意见直接执行；方向变更或冲突才请求决定。

分享采用独立视频副本，弹窗显示版本；已发链接不随修改改变。公开分享无需登录，支持播放/全屏；“自己播放讲解”不意味着强制自动有声播放。

### 制作及接口契约

- 沿用 HyperFrames、GSAP、既有配音/字幕/素材/渲染。六类内部表达为概念拆解、流程、对比、数据变化、因果、素材聚焦；组件使用共享绝对时间，不以墙钟驱动。新 React 组件只有定位、倒退、重复播放和导出一致性验证后才进入可用目录。
- 项目 DESIGN.md 统一字体、色彩、图表、版式和动效；数值来自来源/计算，旁白节奏来自实际音频。配音失败保留结果与恢复入口，不能默默改成无声。
- `GET /api/agent-projects/:id/plan` 提供结构化方案、旧文档、checkpointId、内容revision和ready；确认请求带checkpointId/revision/clientRequestId，冲突返回409，重复请求复用同一任务。
- `video-range` 增加endSeconds；前后端校验版本、起止与视频时长。`GET .../feedback-results` 逐项返回结果与目标版本/定位；段落ID映射跨版本范围，不能直接复用旧全局时间。
- 历史工程、视频和生成素材继续读取、下载；视频生成供应商路由与MCP工具移除，不探测、不调用、不重启历史生成任务。内部旧工程渲染实现保留以支持历史作品。

### 不能降低的发布和验收门槛

前端、Rust、相关API及浏览器检查后，使用不可变发布快照，并核查公开页面脚本/CSS、新交互、分享与服务日志；保留上一版本，不中断已有任务。

交互在1440×900、1024×768、390×844、320×568实测：无页面横向溢出，视频比例正确；键盘完成确认/反馈/版本/分享，弹窗焦点返回；触摸不依赖悬停，输入和发送不被软键盘遮挡；AA文字对比、非颜色状态、减少动效；失败有有限等待和恢复入口，不伪造制作进度、不打断新输入。

三条真实作品分别为单摆周期、假设复利、录屏+图文操作讲解；至少一条竖屏，每条初稿+两轮修改+分享。核对来源/公式/单位、确认画面一致性、无缺字/溢出/黑帧/丢素材/音频截断、字幕语音句级≤300ms、1080p30fps/H.264及所需AAC。修改分别覆盖局部内容与时长变化，保存方案、画面、版本及前后证据。

三名未参与制作的目标观众须实际观看，每条至少两人答对预设三个理解问题中的两个。不能用模型扮演观众；外部服务故障、真实设备未覆盖或人工环节未完成，分别记为未验收。模拟UI检查不等于真实生产通过。
