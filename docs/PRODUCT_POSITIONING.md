# 映芽产品定位

从资料、想法、已有素材或参考视频出发，一起确定内容与风格，做成有审美、能独立讲解、可以直接分享的视频。

首版面向知识创作者、教育培训者与业务讲解者，优先概念、流程和数据讲解，素材剪辑为解释内容服务。创作入口默认参考约 30 秒，用户可调整画幅与时长；最终内容、语言、声音和输出要求在方案中确认。

## 用户流程

准备素材、想法或参考，补充目标观众与重点并统一提交创作 → 大纲与关键画面 → 确认制作 → 视频初稿 → 截图／时间戳反馈 → 修改版 → 分享或下载。

用户不操作时间线、图层、关键帧或参数表，不需要选择新旧工作区。方案使用实际制作源生成的关键画面，批准后沿用到全片。普通局部修改直接执行，重大方向变化再确认方案。

## 制作能力

Remotion 编排和渲染；PPT 信息设计帮助组织层级与视觉；GSAP 和已适配组件执行图形运动；映芽负责理解资料、选择讲法、制作和准确修改。配音、字幕、上传视频选段及图文动画依实际可用能力工作。

Agent 可通过内置 MiniMax H3 skill 生成带声音的镜头素材，并由 Remotion 编排成片；用户在其他工具生成的视频也可上传。产品不提供用户自行连接供应商或填写模型凭据的界面。具体服务与能力边界见[服务集成](INTEGRATIONS.md#minimax-h3-generated-footage)。互动演示、参数录制、完整 PPT 文件编辑与通用混剪不在首版范围。

## 交付判断

清楚讲解、视觉一致、修改准确、输出可靠。技术检查、实际视频审阅与目标观众理解测试分别记录，不以渲染成功代替内容正确，不把界面模拟测试称为真实制作验收。
