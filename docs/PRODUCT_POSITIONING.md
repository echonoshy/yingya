# 映芽产品定位

## 一句话定位

**映芽是对话式动画视频制作工作台：把文案、网页和素材，做成可以持续修改的视频。**

首页主张：**把内容，做成会动的视频。**

用户用自然语言完成内容梳理、方案确认、动画与素材编排、预览修改和成片导出。
HyperFrames 提供可编辑的合成与渲染底座；AI 助手负责制作，图片、配音与配乐能力提供素材。
用户无需编写代码。对外先说明作品与使用方式，技术说明再介绍 HyperFrames。

## 优先用户与场景

首先服务已有内容、需要持续制作和更新短视频的产品营销、内容运营与知识创作者。
优先打磨产品演示和知识讲解，复用同一制作流程支持数据故事、品牌短片与网页转视频。

| 场景 | 输入 | 主要制作方式 |
| --- | --- | --- |
| 产品演示 | 产品截图、录屏、功能说明 | 界面聚焦、操作标注、卖点文字动画 |
| 知识动画 | 文案、知识点、参考资料 | 图形演示、流程展开、旁白与字幕 |
| 数据故事 | 有来源的数据及结论 | 动态图表、数字强调、趋势讲解 |
| 品牌短片 | 品牌文案、标识、图片、视频 | 动态排版、素材编排、节奏转场 |
| 网页转视频 | 可读取的网页或页面截图 | 内容提炼、页面聚焦、品牌一致的讲解 |

以上是制作方向，不表示每个方向已有固定模板。方案必须依据可用工具和实际素材确定。

## 核心价值与能力边界

- **内容讲得清楚。** 文字、数据、界面与图形是主要表达手段，动效帮助观看者理解内容。
- **修改有明确对象。** 用户可以要求改标题、替换素材、调整某一时间段；助手在已有源文件上修改，保留草稿版本。
- **制作可以延续。** 从方案到预览、局部修改和 MP4 导出形成完整流程，项目源文件继续保留。

映芽当前不以“输入提示词生成任意镜头”为能力承诺。新的实拍场景、人物表演和复杂镜头运动
需要用户提供视频，或另行验证可用的视频生成能力。不能将静态图片的缩放平移当作已满足实拍需求。
其他工具生成的视频可以作为素材参与编排；这与映芽的制作定位兼容。

网站不可读取时需要截图或文案；缺少真实数据时需要数据来源。素材生成、配音和配乐依赖
实际可用的服务，不能以定位文案替代能力检查。不同画幅可作为项目要求，不承诺一键批量适配。
当前编辑入口是对话与预览反馈，不承诺完整的拖拽时间线或图层编辑器。

## 产品表达与制作行为

1. 起始页明确说明动画视频制作，提示输入文案、网页、截图、图片或已有视频。
2. 示例给出可执行的内容编排方向，保留用户填写真实资料的位置，不虚构品牌事实或数据。
3. 将“确认方案 → 预览与修改 → 导出成片”放在创作入口附近，保留现有审阅流程。
4. 工作区用“标题放大”“图表多停留 2 秒”等具体例子引导修改，模型选择说明其属于制作助手。
5. 制作助手优先保留可编辑文字、图形和动画；素材工具按内容需要使用，实拍素材缺口在方案阶段说明。

未来可评估品牌规范复用、常用版式、多画幅适配和系列内容制作；这些是候选方向，尚不作为现有功能宣传。

## 技术依据

仓库现有能力包括方案检查点、HyperFrames 实时预览、时间点与画面反馈、版本快照和持久化导出任务。
[HyperFrames 官方说明](https://github.com/heygen-com/hyperframes)将其定义为从 HTML、CSS、媒体和可定位动画渲染视频的框架，与上述定位一致。
